- Added `OpenAIDecisionsClassifier`, which answers classifier questions with OpenAI's Decisions API (`gpt-6-luna`). It takes an OpenAI API key, and several classifiers can share one `OpenAIDecisionsClient`. A choice question can have at most 255 options (`OPENAI_DECISIONS_MAX_CHOICE_OPTIONS`). Install with `uv add "pipecat-ai[openai]"`.

  ```python
  classifier = OpenAIDecisionsClassifier(api_key=os.getenv("OPENAI_API_KEY"))
  results = await classifier.yes_no(
      "Hi, you've reached Dana. Leave a message.",
      {"voicemail": YesNoQuestion(instructions="is this a voicemail?")},
  )
  ```
