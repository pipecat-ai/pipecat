- Added `MCPClient(tools_arguments=...)`, which injects extra arguments into every call of a tool. Use it for arguments the model shouldn't choose — a fixed search mode, an account id, a caller-supplied filter. The pinned arguments override anything the model supplies, and are hidden from the schema it sees:

  ```python
  mcp = MCPClient(
      server_params=...,
      tools_arguments={"search": {"mode": "realtime"}},
  )
  ```

  In this example, the model only ever sees `search(query=...)`, while every call reaches the server as `search(query=..., mode="realtime")`.
