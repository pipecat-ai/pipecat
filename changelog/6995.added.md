- Added two kinds of new affordances to LLM extensions (`BaseLLMExtension`):
  - **Filtering function calls.** `filter_function_calls()` takes the function calls the service is about to run and returns the ones to run. A call it drops is not run, and nothing of it reaches the context or the pipeline.
  - **New ways of asking the service to act**, akin to how an extension asks it to push a frame:
    - `run_function_calls()` runs function calls of the extension's own.
    - `queue_frame()` queues a frame for the service to process.
    - `cancel_inference_in_progress()` cancels the service's inference for a context frame, if it is the one in progress.
