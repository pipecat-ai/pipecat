- Added `vad_force_turn_endpoint` to `ZoomAISTTService`. With `vad_force_turn_endpoint=True`, Scribe's own voice activity detection is turned off and the service commits each turn on `VADUserStoppedSpeakingFrame`, so Pipecat's VAD and turn strategies (e.g. Smart Turn) decide when the user is done. The service then reports a TTFS P99 latency (`ZOOM_AI_TTFS_P99`, overridable with `ttfs_p99_latency`) and leaves the default user turn strategies in place. The default (`False`) keeps Scribe's turn detection unchanged.
