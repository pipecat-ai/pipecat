- `NvidiaSageMakerSTTService` no longer drops all audio for the rest of a session after its SageMaker session fails to start. The failure is reported as an error and the service is marked unusable, so failover and `ProcessorUnusablePolicy` can act on it.
  - `NvidiaSageMakerSTTService` and `NvidiaSageMakerTTSService` classify SageMaker session failures (`RATE_LIMIT`, `SERVER`, `CONNECTIVITY` or `INVALID_REQUEST`), so rejected credentials are reported as `CONNECTIVITY` and a throttled start as `RATE_LIMIT`.
  - `NvidiaSageMakerTTSService` reports a failed session start as an error and stays usable, starting a new session on the next turn.
