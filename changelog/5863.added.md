- Added Pipecat Classifiers. Classifiers are small objects that answer typed questions about some state. A question is a `YesNoQuestion`, a `ChoiceQuestion` among options, or a `ScoreQuestion` on a scale, and questions are asked by name, several about one state at once: `ask()` takes any mix, and `yes_no()`, `choice()` and `score()` take questions of one kind and return typed results: a `YesNoResult` with the probability of yes and `is_yes`, a `ChoiceResult` with the `choice` and a probability per option, a `ScoreResult` with the `score` on the scale. `JevClassifier` answers them through Jev, TypeSafe's classification model, in one request, and several classifiers can share one `JevClient`, the HTTP/2 layer that handles auth, retries and token accounting. Install with `pip install pipecat-ai[jev]`. `examples/features/features-classifiers.py` asks one question of each kind.

  ```python
  classifier = JevClassifier(api_key=os.getenv("TYPESAFE_API_KEY"))
  results = await classifier.choice(
      "I'd like to book a table for, um",
      {
          "turn": ChoiceQuestion(
              instructions="is the user's turn over?",
              options={
                  "complete": "the user finished",
                  "short": "a brief pause",
                  "long": "asked for time",
              },
          )
      },
  )
  results["turn"].choice  # "short"
  ```
