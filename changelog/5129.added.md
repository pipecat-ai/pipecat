- Added `language_codes` setting to `AssemblyAISTTSettings`, exposing AssemblyAI's list-valued declared-language parameter which supersedes the singular `language_code`. It takes `Language` enums: a single language (e.g. `language_codes=[Language.ES]`) pins transcription to that language, while several (e.g. `language_codes=[Language.EN, Language.ES]`) steer toward that subset while keeping code-switching among them. Steering is prompt-based, so it applies to U3 Pro models only; on those models a change applies to the live connection instead of reconnecting, and an empty list clears steering back to the model default.
