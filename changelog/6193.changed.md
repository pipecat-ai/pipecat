- ⚠️ **Breaking change:** Services for OpenAI-compatible providers other than OpenAI now raise `ValueError` when `api_key` is `None` or empty, and `GroqSTTService` and `OpenRouterLLMService` now require `api_key` as an argument. None of these services reads its provider's key from the environment, so pass the key explicitly, e.g. `GroqSTTService(api_key=os.environ["GROQ_API_KEY"])`. `NvidiaLLMService` still accepts no key, for a local NIM.
