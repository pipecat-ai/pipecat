- ⚠️ **Breaking change:** `GroqSTTService` and `OpenRouterLLMService` now require `api_key`. Neither reads `GROQ_API_KEY` or `OPENROUTER_API_KEY` from the environment, so pass the key explicitly, e.g. `GroqSTTService(api_key=os.environ["GROQ_API_KEY"])`. `NvidiaLLMService` still accepts no key, for a local NIM.
