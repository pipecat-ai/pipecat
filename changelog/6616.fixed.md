- Pipecat now reads and writes its own text files as UTF-8 on every platform, so Windows no longer falls back to the system's ANSI code page: the `pipecat eval` worker's config and result files, the `pipecat eval suite` results file, the `pipecat eval judge` output, and the Google STT `credentials_path` file. Existing files read the same, since their contents are ASCII.
