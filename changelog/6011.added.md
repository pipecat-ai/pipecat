- Added a keepalive to `WebsocketTTSService` for custom websocket TTS services whose provider closes idle connections. Pass `keepalive_interval` to the base class, override `_send_keepalive()` to send the provider's keepalive message, and call `_create_keepalive_task()` / `_cancel_keepalive_task()` from `_connect()` / `_disconnect()`. Keepalives are sent only while the websocket is open, and a failed send doesn't stop later ones.
