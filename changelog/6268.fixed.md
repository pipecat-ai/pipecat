- Fixed `PipelineWorker.flush_pipeline()` never draining a pipeline that contains a `ParallelPipeline` (including a `ServiceSwitcher`): it waited until the pipeline went quiet and then returned `False`. This stalled RTVI `send-text` messages with `run_immediately`, which flush the pipeline before adding the user's text. Each of the flush probe's three passes (down, up, down again) is now a new `PipelineFlushFrame` carrying the same new `flush_id` field.
