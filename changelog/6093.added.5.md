- Added the RTVI `user-input` message, the user's counterpart of `bot-output`: what the user said or typed, with an `input_type` of `transcription`, `chat` or `backchannel`, and `final` set to false for an interim transcription. The observer sends one for each transcription, alongside `user-transcription`, and for each `UserBackchannelFrame`. It also acknowledges each `send-text` message, after any interruption it causes, with `input_type` `chat`, the message's id as `msg_id` and, on transports that know the sender such as Daily and LiveKit, their id as `user_id`; `RTVIProcessor` pushes an `RTVISendTextFrame` for this. `RTVIObserverParams.user_input_enabled` turns it off.
