- Added the RTVI `user-input` message, the user's counterpart of `bot-output`: what the user said or typed, with an `input_type` of `transcription` or `backchannel`, and `final` set to false for an interim transcription. The observer sends one for each transcription, alongside `user-transcription`, and for each `UserBackchannelFrame`. `RTVIObserverParams.user_input_enabled` turns it off.
