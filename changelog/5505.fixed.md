- Fixed an issue where auto context summarization would trigger a summarization request on every turn that could never make progress, such as when the initial system message alone exceeded `max_context_tokens`, or when the preserved messages (the system prompt, the last `min_messages_after_summary` messages, unresolved function call sequences) alone exceeded it. In that last case, every new message caused the previous summary to be re-summarized. The token trigger now counts only the messages a summary would actually compress, skips when there is nothing to summarize, and warns once when the context is over the limit but nothing can be summarized. The `max_unsummarized_messages` trigger is not affected.
