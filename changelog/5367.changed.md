- The `cli` extra now requires Pipecat Context Hub 0.5.3 or newer, so a plain `pipecat-ai[cli]` install can run `pipecat context-hub refresh --framework-version latest` — the refresh the agent guides written by `pipecat init` prescribe. It pins the index to the newest released `pipecat-ai` tag instead of `main`, and re-resolves on every run, so a later incremental refresh picks up a new release without `--force`.
