- Added `redact_secrets()` (`pipecat.utils.security.redaction`), which masks credentials in text bound for logs or error reports: values named like a credential (`api_key=`, `Authorization:`, `X-Amz-Signature=`, `'token': '...'`, `apiKey := ...`), URL passwords, and tokens recognizable by format after gitleaks' rules for the same credentials (OpenAI, Anthropic, AWS and Amazon Bedrock, Google, GitHub, Slack, Hugging Face, Perplexity and Twilio keys, JWTs, PEM private keys).
