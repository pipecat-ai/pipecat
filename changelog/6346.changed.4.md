- ⚠️ A user turn stop strategy now only decides whether the user is done. `BaseUserTurnStopStrategy.trigger_user_turn_stopped()` fires `on_user_turn_stopped` and no longer `on_user_turn_inference_triggered`, and it takes `confirms_speculation`. The turn controller runs the turn's inference itself once the stop strategies have decided, so a strategy calls `trigger_user_turn_inference_triggered()` only to speculate, as an eager end of turn does. A call without a speculation no longer starts an inference.
