- ⚠️ A user turn stop strategy now only reports that the user is done. `BaseUserTurnStopStrategy.report_user_turn_stopped()`, which replaces `trigger_user_turn_stopped()`, fires `on_user_turn_stopped` and no longer `on_user_turn_inference_triggered`, because the turn controller now runs the turn's inference itself once the stop strategies have decided. A custom stop strategy starts an inference only to speculate, with `start_user_turn_speculation()`. The deprecated `trigger_user_turn_inference_triggered()` ignores a call without a speculation, with a warning the first time.
