- Added `RimeSTTService`, streaming speech-to-text with Rime. Rime transcribes one utterance per stream, so the service needs VAD frames from the user aggregator or a `VADProcessor`, and streams each speech segment as its own request with interim transcripts and one final. `Settings` take the language, `mode` (`written` or `verbatim`), `context_terms` and `output_contract`. The `rime` extra now installs Rime's `rimelabs-sdk` alongside the TTS client, and `pipecat init` offers Rime as a speech-to-text service.

  ```python
  stt = RimeSTTService(
      api_key=os.getenv("RIME_API_KEY"),
      settings=RimeSTTService.Settings(language="en", context_terms=["Pipecat"]),
  )
  ```
