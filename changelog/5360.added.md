- Added `DeepgramFluxSageMakerTTSService`, running Deepgram Flux TTS on a SageMaker endpoint. It takes `endpoint_name` and `region` instead of an API key and accepts the same settings as `DeepgramFluxTTSService`, including `voice`, `speed` and `expressivity`. Requires `pipecat-ai[deepgram,sagemaker]` and AWS credentials.
