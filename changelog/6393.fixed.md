- `GrokRealtimeLLMService` no longer sends `response.cancel` on an interruption when server VAD is on, where xAI interrupts the response itself. On a one-word user turn, whose `speech_started` and `speech_stopped` arrive together, the cancel landed on the response Grok had just started for that turn, and the bot said nothing until the user spoke again. Manual turn mode still clears the input buffer and cancels the response.
