- Fixed `strip_complete_markup()` (and `split_markup_runs()`) removing the words between a `<` and a later `>` used as comparisons: markup tags must now start with a letter or `/`, so text like "Is 3 < 5 and 7 > 2?" keeps its comparison operators instead of showing as "Is 3  2?". Emoticons like `<3` are unaffected.
