- `resolve_language(..., use_base_code=True)` now resolves a regional variant missing from the map to the map's code for its base language when the map has one (`en-US` becomes `"eng"` for a map with `Language.EN: "eng"`), falling back to the base code (`"en"`) otherwise. This changes the code sent for unmapped regional variants by Meta STT, Pocket TTS, Rime TTS, Camb TTS, Kokoro TTS, XTTS, Neuphonic TTS, and xAI TTS; for example, Rime sends `"ara"` for `Language.AR_AE` instead of `"ar"`.
