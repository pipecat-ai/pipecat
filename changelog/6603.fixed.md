- Fixed a function call that returns a falsy result such as `{}`, `[]`, `0`, `False` or `""` never running the LLM, which left the bot silent, and recording `"COMPLETED"` in the context instead of the value. Any result other than `None` now runs the LLM and is passed on as returned, by `LLMAssistantAggregator` and by the realtime LLM services. A `None` result still completes the call without running the LLM.
