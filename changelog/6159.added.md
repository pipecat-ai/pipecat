- Added `LLMSettings.use_provider_thinking_default`. When it's set, `AnthropicLLMService`, `OpenAIResponsesLLMService`, `OpenAIResponsesHttpLLMService`, `GoogleLLMService` and `GoogleVertexLLMService` send no thinking setting to a model that has none configured, so it runs at its provider's default instead of the lowest setting they send a voice LLM.
