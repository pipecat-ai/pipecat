- Added `GoogleInteractionsVertexLLMService`, which runs `GoogleInteractionsLLMService` on Vertex AI. Import it from `pipecat.services.google.interactions.vertex.llm`.
  - It authenticates with Google Cloud credentials (`credentials`, `credentials_path`, or the application default credentials) for a `project_id`, and refuses an `api_key`.
  - `location` defaults to `"global"`. Vertex serves the Interactions API only from `global`, `us` and `eu`, and only for Gemini 3 models and later; the default model is `gemini-3.8-flash`.
  - `gs://` image and file URLs are passed to Vertex directly.
  - See `examples/function-calling/function-calling-google-interactions-vertex.py`.
