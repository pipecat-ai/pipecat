- Eval scenarios can be judged by TypeSafe's Jev, a fast classifier: set `service: typesafe` in a scenario's `judge.eval:` block. Each check takes a few hundred milliseconds, and Jev's probabilities are calibrated, so a close call can be told from a sure one. It judges through `JevClassifier`, needs `TYPESAFE_API_KEY`, and the `evals` extra now installs the `jev` extra for it.
