- Added a judge for evals backed by TypeSafe's Jev, a fast classifier: set `service: typesafe` in a scenario's `judge.eval:` block (`JevEvalJudge` in `pipecat.evals.jev_judge`). Each check takes a few hundred milliseconds. An LLM `explainer` (the default LLM judge unless set, or `false` for none) gives the reason for every `no` and every verdict below `explain_below`, and Jev's verdict stands. It needs `TYPESAFE_API_KEY`, and the `evals` extra now installs `httpx2[http2]` for it.
