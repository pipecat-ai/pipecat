- Eval scenarios can be judged by any classifier: a `factory:` in the `judge.eval:` block names a callable that takes the block and returns a `BaseClassifier`, or an LLM service the judge then classifies with. The release evals judge with TypeSafe's Jev this way, through `evals/judges.py`: each check takes a few hundred milliseconds and Jev's probabilities are calibrated, so a close call can be told from a sure one. It needs `TYPESAFE_API_KEY`, and the `evals` extra now installs the `jev` extra for it.
