- Added `BaseEvalJudge` (`pipecat.evals.base_judge`), the judge interface the eval harness drives, which `EvalJudge` and `JevEvalJudge` implement, and `judge_from_config()`, which builds the judge a scenario's `judge.eval:` block names. A session takes any `BaseEvalJudge` as its `judge` and closes it when the run ends.
