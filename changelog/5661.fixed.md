- Bots scaffolded by `pipecat init` with Sarvam, Whisper, or Moonshine STT, Sarvam TTS, or Google STT no longer crash at startup. Sarvam and Google STT now use each service's default model or location, and Whisper and Moonshine read an optional `WHISPER_MODEL` or `MOONSHINE_MODEL` variable that falls back to the default model. Previously the generated code read a variable the generated `.env.example` never listed, and the unset variable arrived as an explicit `None` that overrode the working default and failed validation.
