- Fixed `NvidiaSegmentedSTTService` ignoring `speaker_diarization`. Diarization is now requested, and with a model that returns word-level results, such as `parakeet-ctc-1.1b-asr`, each contiguous speaker run of a segment is emitted as its own `TranscriptionFrame` with NVIDIA's speaker tag in `speaker_label`. The default `canary-1b-asr` returns no word-level results, so its segments stay unlabelled.
