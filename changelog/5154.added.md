- Added an opt-in `force_locale` setting to `AzureTTSService` and `AzureHttpTTSService` (`AzureTTSSettings`) that wraps synthesized text in SSML's `<lang xml:lang>` element, forcing multilingual voices (e.g. `en-US-EmmaMultilingualNeural`) to speak in the configured locale/accent instead of auto-detecting it per segment. Defaults to `False`, producing the same SSML as before.
