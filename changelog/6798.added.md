- Added `DeepgramSegmentedSTTService`, a segmented speech-to-text service backed by Deepgram's pre-recorded API: pipeline VAD segments the audio and each segment is transcribed in one HTTP request, with no WebSocket connection to keep alive. It takes an `aiohttp_session`, and `base_url` selects a regional or self-hosted endpoint.

`Settings` takes the settings Deepgram's streaming and pre-recorded APIs share (`model`, `language`, `keyterm`, `smart_format`, `diarize`, `speaker_format`, ...), plus `detect_language` and `filler_words`; any other pre-recorded query parameter can be passed through `extra`. With `detect_language`, each transcript carries the language Deepgram detected. With `diarize=True`, each speaker run of a segment is its own `TranscriptionFrame` with a `speaker`, and `diarize_model` (default `"latest"`) selects Deepgram's diarization model.
