- Fixed `GoogleLLMService` leaving a user turn unanswered on models that continue a trailing model turn, such as `gemini-3-flash-preview`, when an inference ran after an incomplete-turn marker (`◐`/`○`) had been added to the context. A request whose context ends with a stand-alone turn completion marker now gets the trailing `"."` user turn on every model, so the model answers the turn instead of continuing the marker.
