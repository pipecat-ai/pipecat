- Added `ClassifierUserTurnStopStrategy` and `ClassifierUserTurnStrategies`, which let a classifier, such as `JevClassifier`, decide whether the user's turn is complete. They're an alternative to `FilterIncompleteUserTurnStrategies` for an LLM that doesn't follow the turn-completion markers well. At every pause with new words, the classifier judges the turn so far from the user's words and the bot's last line: `complete` ends the turn, and `short` and `long` keep it open for a few seconds unless the user continues. `ClassifierUserTurnStrategies` adds the classifier to the default stop strategies (smart turn), and the turn ends once both have decided; for the classifier alone, pass `UserTurnStrategies(stop=[ClassifierUserTurnStopStrategy(...)])`.

  ```python
  user_params = LLMUserAggregatorParams(
      user_turn_strategies=ClassifierUserTurnStrategies(
          classifier=JevClassifier(api_key=os.getenv("TYPESAFE_API_KEY")),
          context=context,
      ),
  )
  ```
