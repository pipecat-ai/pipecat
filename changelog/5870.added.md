- Added `ClassifierUserTurnCompletionStopStrategy` and `ClassifierUserTurnStrategies`, which let a classifier decide whether the user's turn is complete. When a detector such as smart turn fires, the strategy asks the classifier instead of ending the turn: `complete` ends it, `short` and `long` keep it open for a timeout, and if the user continues the whole turn is classified again. The LLM runs only when a turn is complete, so unlike the marker-based `FilterIncompleteUserTurnStrategies` it never sees an unfinished turn.

  ```python
  user_params = LLMUserAggregatorParams(
      user_turn_strategies=ClassifierUserTurnStrategies(
          classifier=JevClassifier(api_key=os.getenv("TYPESAFE_API_KEY")),
          context=context,
      ),
  )
  ```
