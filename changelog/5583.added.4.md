- The SIP transport now surfaces the native stack's logs in Pipecat's log
  output (bridged from baresip-python's `baresip.*` loggers) and exposes
  debugging knobs: `SIPConnection(native_log_level=..., sip_trace=...)`,
  where `sip_trace` logs every SIP message verbatim — the tool for
  signaling and SDP/media-path debugging. With the development runner, set
  `SIP_NATIVE_LOG_LEVEL` and `SIP_TRACE=1`.
