- Fixed an LLM service's built-in tools (the tools the framework adds on the service's behalf, such as the `cancel_<tool>` tool for a tool registered with `cancellable_by_llm=True`, or `PipecatDualLLMService`'s `delegate`) never reaching the provider when the context advertised no tools of its own. That is the case for a realtime service whose tools are given at construction, via `tools=` or a session's properties, rather than through the context: a cancellable tool given that way had no cancel tool at the provider. Fixed the realtime services (OpenAI, Grok and Inworld Realtime, Gemini Live, Nova Sonic) dropping those constructor-given tools whenever the context's only tools were built-in ones. Built-in tools are now sent on every inference alongside whatever tools the context or the service provides.
