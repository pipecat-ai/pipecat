- Added `PerplexityAgentLLMService` for Perplexity's Agent API, which answers with web search and supports function calling. It defaults to Perplexity's `fast` preset with `openai/gpt-5.6-luna` and web search on.
  - `Settings` adds `preset`, `web_search` and `max_steps`. `preset` and `model` are independent, and at least one must be set.
  - Without a preset, reasoning is off for OpenAI models unless `reasoning` is set; a preset decides how much to reason.
  - Answers can include citation markers such as `[1]`, and Anthropic models need `max_completion_tokens` set.
