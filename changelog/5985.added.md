- Added `PerplexityAgentHttpLLMService` for Perplexity's Agent API, which answers with web search and supports function calling. It defaults to `openai/gpt-5.6-luna` with web search on.
  - `Settings` adds `preset`, `web_search` and `max_steps`. `preset` and `model` are independent, and at least one must be set.
  - With neither `preset` nor `reasoning` set, each request sends Perplexity's `fast` preset, its lowest-latency setup, and the first request for each model logs it. With `use_provider_thinking_default` set, no preset is sent.
  - Answers can include citation markers such as `[1]`, and Anthropic models need `max_completion_tokens` set.
