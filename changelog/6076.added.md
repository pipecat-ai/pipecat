- `NvidiaSTTService` now exposes speaker diarization in transcription frames. When `speaker_diarization` is enabled, each contiguous speaker run is emitted as its own frame with the NVIDIA speaker tag in `user_id`. The new `speaker_format` setting optionally adds speaker labels to the transcript text: `settings=NvidiaSTTService.Settings(speaker_diarization=True, speaker_format="Speaker {speaker}: {text}")`.
