- Reduced per-frame CPU cost in the `FrameProcessor` push path. The `logger.trace` calls in `__internal_push_frame` now defer message formatting to loguru instead of building the string on every push, the event-handler dispatch in `push_frame` and `__process_frame` is skipped when no handler is registered, and the observer timestamp is read only when an observer is attached. Measured over a pipeline of 8 queued pass-through processors at 1,500 frames per window: 0.743 median wall-time ratio against an untouched control of 0.996, both n=3. Trace messages, observer streams, frame order and per-processor delivery counts are unchanged.
