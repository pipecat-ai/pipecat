- `GoogleLLMService.run_inference()` now logs a warning naming Gemini's `finish_reason` when a reply ends for a notable reason, as streamed responses already do. Previously a one-shot inference that was withheld for safety or cut off at the output token limit returned `None` or partial text with no indication why, which affected features built on it such as context summarization and the LLM classifier. Partial text is still returned.
