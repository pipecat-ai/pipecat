- `OpenAIResponsesLLMService` and `OpenAIResponsesHttpLLMService` now log a warning and push a non-fatal `ErrorFrame` when a response completes with no text and no function call. Nothing reaches the TTS for such a response, so the bot stays silent until the user speaks again; the error lets the application react in `on_pipeline_error`, for example by running the LLM again. The warning lists the response's output items, such as `['reasoning']` or `['message[refusal]']`, and the WebSocket service also logs whether the request sent the full context or only the items added since the previous response.
