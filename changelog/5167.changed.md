- ⚠️ `AzureLLMService` no longer defaults `model` to `"gpt-4.1"` and now raises a `ValueError` at construction if no model is provided via `settings=AzureLLMService.Settings(model=...)`. On Azure OpenAI, `model` is the deployment name you chose on your resource, not the model family, so there is no universally correct default — a missing name would previously surface only as a `DeploymentNotFound` 404 at first inference.
