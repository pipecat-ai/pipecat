- The SIP transport now accepts raw baresip account parameters via
  `SIPConnection(extra_params=...)`, each a `"key=value"` string appended
  verbatim to the SIP address-of-record — the escape hatch for account
  directives Pipecat does not model. Media-NAT traversal is the common case:
  `extra_params=("medianat=stun", "stunserver=stun:HOST:PORT")` makes baresip
  advertise its STUN-discovered public media address, the traversal a non-ICE
  peer (such as a PSTN SIP trunk) needs for calls behind NAT. The development
  runner (`-t sip`) enables this by default: when `SIP_EXTRA_PARAMS` is unset it
  adds `medianat=stun` using `SIP_STUN_SERVER` (default stun.l.google.com). Set
  `SIP_STUN_SERVER=off` to disable it, or `SIP_EXTRA_PARAMS` to override.
