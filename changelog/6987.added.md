- Added `PlivoTTSService` and `PlivoHttpTTSService`, text-to-speech with [Koyal](https://www.plivo.com/docs/models/text-to-speech/overview), Plivo's TTS model. `PlivoTTSService` streams over Plivo's Realtime API on one WebSocket, with one context per turn and word timestamps; `PlivoHttpTTSService` sends one Batch API request per sentence. Install with `pipecat-ai[plivo]`.
