- RTVI now reports backchannels. The observer sends a `user-backchannel` message for each `UserBackchannelFrame`, and a `bot-backchannel` message when the bot starts saying text of type `backchannel`, instead of `bot-output` and `bot-tts-text` messages. `RTVIObserverParams.user_backchannel_enabled` and `bot_backchannel_enabled` turn either off. The RTVI protocol version is now 2.3.0.
