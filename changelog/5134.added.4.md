- Added the `on_pipeline_configuration_error` event handler, called with the `ErrorFrame` a misconfigured service reported, once per service rather than once per failed request.

    ```python
    @worker.event_handler("on_pipeline_configuration_error")
    async def on_pipeline_configuration_error(worker, frame):
        logger.error(f"{frame.processor} needs attention: {frame.error}")
    ```

    It fires before `on_configuration_error` is applied, so handlers can react regardless of whether the pipeline is about to stop.
