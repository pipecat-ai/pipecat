- Removed `AICVADAnalyzer`, `AICFilter.create_vad_analyzer()`, and `AICFilter.get_vad_context()`. `aic-sdk` 3.0 removed the energy-based VAD all three relied on. The first two were deprecated since 1.4.0; `get_vad_context()` was not, so calls to it need replacing with `AICQuailVADAnalyzer`, which runs a dedicated VAD model.
