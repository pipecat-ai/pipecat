- Fixed a job group losing the events a worker sends while the requests to the
  rest of the group are still going out. The group's event queue is now in place
  before the first request is published, so `async for` over a
  `JobContext`/`JobGroupContext` sees every update and streaming chunk. Only
  buses whose `publish()` awaits were affected, which is every network bus;
  `AsyncQueueBus` was not.
