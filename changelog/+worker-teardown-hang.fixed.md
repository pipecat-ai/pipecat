- Fixed `PipelineWorker.run()` never returning when it was cancelled together with the worker's own tasks, as `asyncio.run()` does with every task left when it exits. The process hung instead of exiting, e.g. on Ctrl+C in the development runner while a session started from `/start` was running, or when an app's main coroutine raised while a `WorkerRunner` was running. The pipeline is now cleaned up and the worker finishes.
