- `pipecat.adapters.base_llm_adapter`, `pipecat.adapters.schemas.*` and `pipecat.adapters.services.*` are deprecated. Use `pipecat.adapters.llm.base_llm_adapter`, `pipecat.adapters.llm.schemas.*` and `pipecat.adapters.llm.services.*` instead (for example, `from pipecat.adapters.llm.schemas.function_schema import FunctionSchema`). The module names are unchanged, and the old paths still work, with a deprecation warning, until 2.0.0.
  - Workers on a shared bus send tool schemas under their new module path, so a worker on an earlier Pipecat version can't read the tool schemas a worker on this version sends. Upgrade the workers that share a bus together.
