Added `LLMUserAggregatorParams.empty_user_turn`, which takes an
`EmptyUserTurnConfig` to answer user turns that end with no transcript. When
such a turn interrupted the bot, the aggregator appends a developer message and
runs the LLM once, so the bot asks the user to repeat instead of going silent.
Turns while the bot was idle are treated as noise and left unanswered unless
`idle_prompt` is set.
