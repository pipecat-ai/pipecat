- Added `LLMWithBackend` (`pipecat.pipeline.llm_with_backend`), in alpha: a conversational frontend LLM (text or speech-to-speech) with a backend LLM (in a `BackendLLMWorker`) it delegates to for deeper thinking and tool orchestration. The frontend keeps the conversation moving fluidly while the backend does the heavy lifting, sending messages to the frontend as it works. An `LLMWithBackend` drops into a pipeline where a standalone LLM would go, with the frontend's system instruction defining who the assistant is while the backend's defines in more detail what work it does. Behind the scenes, the frontend calls a `delegate` tool and receives a stream of backend outputs, with a `BackendConnector` as the (configurable) glue defining how the two pieces interact. See `examples/multi-worker/llm-with-backend/`.

  ```python
  llm = LLMWithBackend(
      frontend=OpenAIResponsesLLMService(...),
      backend=BackendLLMWorker(
          llm=AnthropicLLMService(...),
          context=LLMContext(tools=[search_codebase, read_file, apply_patch, run_tests]),
      ),
  )
  pipeline = Pipeline([transport.input(), stt, user_agg, llm, tts, transport.output(), assistant_agg])
  ```
