- ⚠️ The SIP transport now requires `baresip-python>=0.7.0`, which verifies TLS servers: a `transport="tls"` account fails to register when the server's certificate does not chain to a trusted CA or does not name the host connected to. For a server with a private or self-signed certificate, point `SIP_CA_FILE` at its CA certificate; a server reached by IP address needs a certificate that carries that address. With the new version a received call that offers SRTP is answered and encrypted where it was refused with 488, a blind transfer sends its target in angle brackets, and calls routed through `sips:` addresses complete.
