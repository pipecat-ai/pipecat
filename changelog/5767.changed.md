- `pipecat init` React clients (Vite and Next.js) now use [Pipecat UI](https://ui.pipecat.ai), the shadcn registry that succeeds `@pipecat-ai/voice-ui-kit`. The generated client renders the Pipecat UI console (connect flow, transcript, metrics, device and session info, and a live event stream) with a transport picker in its header. Components are installed as source under `src/components/pipecat`, `src/hooks` and `src/lib`, with a `components.json` that points at the `@pipecat` registry so they can be extended or updated with the shadcn CLI; the README shows the minimal composition for building a custom UI from them. The vanilla JavaScript client is restyled to match.
