- Added subflows to `FlowConfig`: a set of nodes is written once under `flows` and used through `includes`, each include naming the subflow and the `return_to` its `return` leads to. A transition target, `initial_node` or `return_to` may name an include, and `Flow` builds its nodes as `<include>.<node>`. A config that uses subflows cannot have a `.` in a node name or include id.
