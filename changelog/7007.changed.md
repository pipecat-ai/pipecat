- Since 1.17.0, `SarvamRealtimeSTTService` defaults to `saaras:v4` (previously `saaras:v3-realtime`); the 1.17.0 notes didn't mention it. `saaras:v3-realtime` is in beta and Sarvam refuses it for API keys not enrolled in the beta. Select it with `Settings(model="saaras:v3-realtime")` to keep using it.
