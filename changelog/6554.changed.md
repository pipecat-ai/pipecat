- With expressive conversation on, the user aggregator merges all the final readings of a user turn, instead of keeping only the last one, so a reading from earlier in the turn, such as a sarcastic first sentence, still reaches the LLM. The new `merge_perception()` in `pipecat.expressive.perception` keeps the higher of each signal: a value keeps its highest value, and labels keep every label read, each with its highest confidence, likeliest first. The merged reading is written at the head of the user message and reported in `on_user_turn_stopped`.
