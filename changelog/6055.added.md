- Added `video_in_sources` support to `LiveKitTransport`, capturing each listed source from a participant at its own framerate, or only to answer image requests with `on_request_only=True`. It also answers a `UserImageRequestFrame` with the next frame of the requested source, so image-request tools such as `fetch_user_image` work on LiveKit, and a request for a source with no subscribed track gets an error result. `LiveKitTransport.capture_participant_video()` captures a source at a framerate. Without `video_in_sources`, every frame of every video track is passed on.
