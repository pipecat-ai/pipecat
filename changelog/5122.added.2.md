- Added `pipecat context-hub` to the CLI's list of official plugins, so it appears in `pipecat --help` whether or not the Pipecat Context Hub is installed, and prints how to enable it when run without it — the same discovery path `pipecat cloud` already had. Install alongside the CLI with `uv tool install "pipecat-ai[cli]" --with pipecat-ai-context-hub`. The scaffolded agent guides now teach `pipecat context-hub` as the primary way to query the hub, with `uvx pipecat-ai-context-hub` as the no-install fallback, and point at `pipecat context-hub install` for one-step setup.
