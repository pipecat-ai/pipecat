- Added `SarvamRealtimeSTTService` for low-latency streaming speech-to-text with Sarvam's `saaras:v3-realtime` model. Supports server-side endpointing (`endpointing="vad"`) and pipeline-driven endpointing (`endpointing="manual"`), interim and final transcripts, timestamps, and in-band configuration updates via `config.update`.

    The service requires a VAD analyzer in either mode, and accepts 8 kHz or 16 kHz audio.

    ```python
    from pipecat.services.sarvam.stt import SarvamRealtimeSTTService

    stt = SarvamRealtimeSTTService(
        api_key=os.getenv("SARVAM_API_KEY"),
        settings=SarvamRealtimeSTTService.Settings(language_code="auto"),
    )
    ```
