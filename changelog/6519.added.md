- Added `PerceptionReader` to expressive conversation (alpha), a processor that reads how each user turn was said by asking any classifier. Place it after the STT service: it asks its classifier about each final transcription, with the bot's previous reply, and sets the answers as the transcription's `perception`, one signal per question. A `ChoiceQuestion` reports its likeliest options, a `YesNoQuestion` its probability and a `ScoreQuestion` its position on the scale. Each `PerceptionQuestion` carries the `description` the LLM is given for its signal. A transcription waits for its reading up to `timeout` seconds, 0.5 by default, and passes unread after that.

  ```python
  from pipecat.expressive.processors.perception_reader import PerceptionQuestion, PerceptionReader

  reader = PerceptionReader(
      classifier=JevClassifier(api_key=os.getenv("TYPESAFE_API_KEY")),
      questions={
          "frustration": PerceptionQuestion(
              question=YesNoQuestion(instructions="Is the user frustrated?"),
              description="The chance the user is frustrated, from 0 to 1.",
          ),
      },
  )
  ```
