- Added `PerceptionReader` to expressive conversation (alpha), a processor that reads how each user turn was said by asking classifiers. Place it after the STT service and give it its `sources`, each a `PerceptionSource`: a classifier, the questions it's asked and how long a transcription waits for its answers. A text classifier reads each final transcription, with the bot's previous reply, and one that hears, such as `HumeAudioClassifier`, hears the user's speech. The sources are asked at once and their answers added to the transcription's `perception`, one signal per question, in the sources' order, after any signals the STT service read (`replace_perception=True` replaces them instead); a source that's late or fails leaves only its own signals out. A `ChoiceQuestion` reports its likeliest options, a `YesNoQuestion` its probability and a `ScoreQuestion` its position on the scale, and each `PerceptionQuestion` carries the `description` the LLM is given for its signal.

  ```python
  from pipecat.expressive.processors.perception_reader import (
      PerceptionQuestion,
      PerceptionReader,
      PerceptionSource,
  )
  from pipecat.expressive.processors.tone_reader import PipecatToneSource

  hume = PerceptionSource(
      classifier=HumeAudioClassifier(api_key=os.getenv("HUME_API_KEY")),
      questions={
          "hesitation": PerceptionQuestion(
              question=YesNoQuestion(instructions="Is the user unsure?"),
              description="The chance the user is unsure, from 0 to 1.",
          ),
      },
  )
  reader = PerceptionReader(sources=[PipecatToneSource(), hume])
  ```
