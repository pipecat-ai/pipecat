- The RTVI `user-transcription`, `bot-llm-text` and `bot-tts-text` messages are deprecated and will be removed in 2.0.0. Use `user-input` for what the user said, or `stt-raw-text`, `llm-raw-text` and `tts-raw-text` for each processor's raw output. They're still sent by default until then. `RTVIObserverParams.user_transcription_enabled`, which only turns off `user-transcription`, is deprecated with it.
