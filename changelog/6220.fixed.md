- `AWSBedrockLLMService` no longer sends Amazon Nova's `<thinking>...</thinking>` reasoning to TTS. Nova (v1) models write it into the answer text before calling a tool, so voice bots read it aloud. A `<thinking>` block that opens a text block is now emitted as `LLMThoughtStartFrame` / `LLMThoughtTextFrame` / `LLMThoughtEndFrame`.
