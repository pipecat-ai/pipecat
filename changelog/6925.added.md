- Added `DraftVerificationLLMExtension`, an LLM extension that has a second, stronger model check each reply of a fast text LLM and correct it. Attach it with `LLMService.Settings(extensions=[DraftVerificationLLMExtension(verifier=LLMDraftVerifier(llm=...))])`. With `hold_secs` set, a reply waits that long for its verdict and a correction replaces it before it is spoken; a later correction is spoken after the reply, or dropped with `late_corrections=False`. A verdict is dropped once the user speaks, interrupts, or a new inference starts, and replies that call tools are not checked.
