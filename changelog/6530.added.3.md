- `PerceptionReader` can read how the user sounded with a classifier that can hear (its `supports_audio`), such as `HumeAudioClassifier`. It keeps the user's recent speech across turns, without the silence in between, and each time the user pauses it sends the speech since the last clip, topped up with the user's earlier speech when that's shorter than the classifier's `min_audio_secs`. A final transcription waits for the latest clip's answers, up to `timeout` seconds after the user stopped (2 by default for an audio classifier), and otherwise gets the turn's latest clip answered. The reader holds the final transcriptions of the user's speech until the user stops speaking (up to 5 seconds) and the STT has sent the rest, then passes them on together with the reading, the last one marked `finalized` so the user's turn ends as soon as it arrives. It also adds `timeout` to the `ttfs_p99_latency` of the `STTMetadataFrame` it passes on, so the turn doesn't end while it still holds a transcription. A text classifier's transcription still goes on as soon as it's read. See `examples/expressive-conversation/expressive-conversation-hume-audio-decisions.py`.
