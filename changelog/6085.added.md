- Added `NvidiaOmniLLMService` for NVIDIA Nemotron Omni models, which take speech, images, and video as well as text. In audio input mode (the default, set with the `audio_input` constructor argument), Omni hears the user directly and replaces the STT service: it transcribes and answers each spoken turn in a single request, and pushes the user's transcript upstream for the context. In this mode it behaves like a realtime service that still needs a TTS. It announces itself as a realtime service, which switches the user aggregator into realtime mode, so read the user's text from `on_user_turn_message_added` rather than `on_user_turn_stopped`. With `audio_input=False`, it is a text LLM for a cascaded pipeline. Audio and video files in the context, from `LLMContext.create_file_message()` or `create_audio_message()`, are sent in the form Omni reads by the new `NvidiaOmniLLMAdapter`. `run_multimodal_inference()` runs a one-off request outside the conversation, for example to describe a video clip, with optional streaming callbacks for text and reasoning. See `examples/voice/voice-nvidia-omni.py`.
