- The development runner's Twilio serializer now reads `TWILIO_API_KEY` and `TWILIO_API_SECRET`, so auto hang-up can authenticate with a Twilio API key instead of the Auth Token, and `TWILIO_REGION` and `TWILIO_EDGE`, so it hangs up calls in a non-US1 region such as `ie1` / `dublin`. Set `TWILIO_AUTH_TOKEN` or the API key pair, not both.
