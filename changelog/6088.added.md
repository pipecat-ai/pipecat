- Added `any_time_after: turn_start` to the scripted eval scenario language (`pipecat.evals`). A turn's `expect:` list is met in order, each expectation only once the one above it has been met, so the list is also a claim about order; the key lifts that claim for one expectation, which may then be met by an event from anywhere in the turn, including before the expectations above it were met, while the ones below it still wait for it. It is for an event whose timing the bot does not set, such as a call a backend makes at its own pace or a reply some models give before a tool call and others after. Added `evals/llm-with-backend/`, the behavioral eval suite for the `LLMWithBackend` examples, which uses it.
