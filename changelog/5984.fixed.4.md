- Fixed `GoogleLLMService` and `GeminiLiveLLMService` leaving tool results out of `prompt_tokens`. When Gemini runs code execution, reads a URL with URL context, or (on some models) grounds with Google Search, the results fed back to the model are billed as input but were reported only in `total_tokens`. `prompt_tokens` now includes them, so it can rise sharply on those turns: a URL-context turn can add several thousand input tokens.
