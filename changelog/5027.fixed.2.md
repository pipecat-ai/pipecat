- Fixed services that send the system instruction as a separate parameter (e.g. `AnthropicLLMService`, `AWSBedrockLLMService`, `GoogleLLMService`) permanently rewriting a lone `system` message in the `LLMContext` to `user`. When a context's only message is a system message, it's converted to `user` so the provider isn't sent an empty conversation history; that conversion now happens on a copy, so the context keeps its `system` role and later turns — once more messages have accumulated — still send it as the system instruction.
