- `SpeechifyHttpTTSService` no longer accepts the legacy `simba-english` and `simba-multilingual` models. Speechify retires them at the API version the service now pins, so requests naming them fail with `model_retired`, including on workspaces whose default version still allowed them. Use `simba-3.2` (English) or `simba-3.0` (multilingual) instead.
