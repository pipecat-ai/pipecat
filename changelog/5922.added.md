- Added `LLMAssistantAggregatorParams.function_call_limit`, a `FunctionCallLimitConfig` that limits how many LLM responses in a row can call functions. After `max_iterations` such responses, the assistant aggregator runs the LLM with the context tool choice set to `"none"` and an optional developer message, so the LLM answers instead of calling again. An LLM response with no function call, or an interruption, resets the count and restores the tool choice.
