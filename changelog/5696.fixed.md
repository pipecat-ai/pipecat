- Flows functions no longer produce asides such as "By the way, your party size has been noted" after a tool call. Every Flows function was being treated as an async tool because Flows registers functions with `cancel_on_interruption=False` so an interruption cannot skip a transition, and the async-tool protocol delivered each result with an instruction to convey it. Flows now registers its functions with `async_tool=False` as well: the LLM waits for the result, the transition happens before it speaks again, and the result lands as a plain tool result. `flows_tool_options(async_tool=True)` opts a Flows tool into the async protocol on purpose.
