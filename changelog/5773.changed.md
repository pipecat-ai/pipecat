- `SpeechmaticsSTTService` now defaults `turn_detection_mode` to `TurnDetectionMode.EXTERNAL`, so Pipecat's own VAD drives turn boundaries through `finalize()`. Set `settings=SpeechmaticsSTTService.Settings(turn_detection_mode=TurnDetectionMode.VAD)` to keep letting the Speechmatics service run its own VAD and close turns itself.
