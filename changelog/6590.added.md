- Added `AsyncToolLLMExtension`, the LLM extension every `LLMService` has, which teaches the model about its asynchronous tools: it adds the async-tool guidance to the system instruction while an asynchronous tool is registered, and a `cancel_<name>` built-in tool for each tool registered with `cancellable_by_llm=True`, so the model can drop work whose result is no longer wanted. The cancel tool's handler acts on the calls in flight through the new `LLMService.running_function_calls()` and `cancel_function_call()`, which any tool handler can use.
