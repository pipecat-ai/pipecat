- Added `sources` to `PerceptionReader`, so one reader asks several classifiers about each user turn, such as one that reads the turn's words and one that hears its audio. Each `PerceptionSource` is a classifier with its own questions and timeout. The sources are asked at once, and their signals go in the turn's one reading, in the sources' order. A source that's late or whose classifier fails leaves only its own signals out, and two sources can't report a signal of the same name.

  ```python
  from pipecat.expressive.processors.perception_reader import (
      PerceptionQuestion,
      PerceptionReader,
      PerceptionSource,
  )
  from pipecat.expressive.processors.tone_reader import PipecatToneSource

  reader = PerceptionReader(
      sources=[
          PipecatToneSource(),
          PerceptionSource(
              classifier=HumeAudioClassifier(api_key=os.getenv("HUME_API_KEY")),
              questions={
                  "hesitation": PerceptionQuestion(
                      question=YesNoQuestion(instructions="Does the speaker sound unsure?"),
                      description="The chance the user sounded unsure, from 0 to 1.",
                  ),
              },
          ),
      ],
  )
  ```
