- Added `IncompleteUserTurnFilter`, a user turn filter that ends a turn only when the LLM marks it complete with ●. On ◐ or ○ it keeps the turn open and, if the user stays quiet for the configured timeout, asks the LLM to re-engage them. It replaces `FilterIncompleteUserTurnStrategies`: set `LLMUserAggregatorParams(user_turn_filter=IncompleteUserTurnFilter())`.
