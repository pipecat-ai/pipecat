- Fixed a user turn ending on the user's earlier words with segmented STT services such as `WhisperSTTService`, `OpenAISTTService`, `GroqSTTService` and `MoonshineSTTService`. When the user spoke again before an earlier segment was transcribed, that segment's transcript was marked finalized, so the stop strategies took it as the user's last words and could end the turn before the new words were transcribed. `SegmentedSTTService` now marks a transcript finalized only when the user hasn't spoken again since its segment ended.
