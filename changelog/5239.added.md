- Added `AICFilterVADAnalyzer`, which reports voice activity detected by an
  `AICFilter` rather than running its own model. `AICFilter` accepts a
  `vad_model_id` (or `vad_model_path`) and runs that VAD on each block before
  enhancing it, so detection sees the original signal — the ordering the
  ai-coustics SDK requires when enhancement and VAD run together. Use
  `AICQuailVADAnalyzer` when no AIC enhancement is in the pipeline.
