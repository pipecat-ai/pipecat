- Added `AICFilterVADAnalyzer` for pipelines that run AIC enhancement. `AICFilter` accepts a `vad_model_id` (or `vad_model_path`) naming a dedicated VAD model such as `vad-2.1-xxs-16khz`, loads it into its own `VadAsync`, and runs it on each block *before* enhancing that block, so detection sees the original signal rather than enhanced output. The analyzer owns no model of its own; it reports the filter's predictions to the pipeline. Prefer `AICQuailVADAnalyzer`, which loads and drives its own VAD, when no AIC enhancement is in the pipeline.
