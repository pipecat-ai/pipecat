- Classifiers can now answer questions about images. `ask()`, `yes_no()`, `choice()` and `score()` take `images=`, a list of `ClassifierImage` (PNG, JPEG or WebP), and `ClassifierImage.from_frame()` builds one from an image frame such as a frame from the user's camera. `ClefClassifier` takes up to 4 images per call (`CLEF_MAX_IMAGES`), and `LLMClassifier` sends them to its LLM, which must be able to see them. A classifier says whether it can see images in `supports_images`, and one that cannot, such as `JevClassifier`, raises `ClassifierError` when given some.

  ```python
  image = await ClassifierImage.from_frame(frame)
  results = await classifier.yes_no(
      "A frame from the user's camera.",
      {"person": YesNoQuestion(instructions="Is there a person in the frame?")},
      images=[image],
  )
  ```
