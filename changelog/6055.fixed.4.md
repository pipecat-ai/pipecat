- Fixed image requests on `DailyTransport` and `SmallWebRTCTransport` that no video frame would answer leaving the function call that made them waiting forever, for example a `fetch_user_image` call while the user's camera is off. A request for a video source the user isn't sending, and any request still waiting when the user leaves or the transport disconnects, now completes with an error result the LLM can act on. On Daily, so does a request still waiting when the user turns that source off. `LiveKitTransport` behaves like Daily.
