- Deprecated the `api_version` constructor parameter on `AzureLLMService`, which will be removed in 2.0.0. Point `endpoint` at Azure's v1 API surface instead, by ending it in `/openai/v1`. Azure issued no dated version after `2025-04-01-preview`, and new features reach only the v1 surface. Endpoints outside that surface still route through `2025-04-01-preview`; passing `api_version` explicitly still applies and now emits a `DeprecationWarning`.
