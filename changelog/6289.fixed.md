- Fixed `GeminiLiveLLMService` configuring the session with only the `system_instruction` it was constructed with. The model now receives the full system instruction `LLMService` composes, including the async-tool guidance, text added with `append_system_instruction()`, and turn-completion instructions; the session reconnects on the first context to pick it up. As with other LLM services, when the composed instruction is all there is (no `system_instruction` of your own), it replaces a `system` message in the context, so set the prompt on `system_instruction` instead.
