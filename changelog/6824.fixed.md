- Fixed `LLMAssistantAggregator` starting an LLM run, requested by a function call result or an `LLMMessagesAppendFrame` with `run_llm=True`, while a response was still being generated. The run now waits until the response has ended and the bot has stopped speaking, so the model no longer answers the same turn twice. A deferred run is also no longer dropped when the response's text is committed to the context.
