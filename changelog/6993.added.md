- The development runner now prints a `pipecat://connect` link and a QR code of it when it listens on a network address (e.g. `--host 0.0.0.0`) with the WebRTC or Daily transport enabled. Scanning the code with a phone opens the Pipecat Playground app connected to the bot. The QR code needs `segno`, which the `runner` extra now installs; without it, only the link is printed.
