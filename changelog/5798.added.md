- Added `TTSService.pronounce_ipa()` and `pronounce_arpabet()`, which build a text transform from a word-to-phonemes mapping so a voice says names and terms it would otherwise guess from spelling. Each matched word is replaced with the service's `format_pronunciation()` output, so one mapping works with any service that supports its alphabet; a word the service cannot use is reported once when the transform is built and spoken as written. Cartesia writes IPA as inline phoneme blocks, ElevenLabs as SSML `<phoneme>` tags in IPA or CMU Arpabet, Eleven v3 and Inworld as IPA between slashes, and Deepgram Aura-2 as an inline pronunciation object. Deepgram Flux has no pronunciation markup, so its words are spoken as written. `pipecat.utils.text.phonemes` holds the parsing and normalization the formatters share, along with IPA-to-Arpabet conversion.

  ```python
  pronounce = CartesiaTTSService.pronounce_ipa(
      {"Metformin": "mɛtˈfɔɹmɪn"}
  )

  tts = CartesiaTTSService(text_transforms=[("*", pronounce)])
  ```
