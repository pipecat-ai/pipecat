- `GeminiLiveLLMService` now supports the Gemini 3.8 Live family: `gemini-3.8-live` and `gemini-3.8-live-extended-thinking`. Both use the Gemini 3.x session protocol, and both support `NON_BLOCKING` function declarations — unlike other Gemini 3.x models — so tools registered with `cancel_on_interruption=False` keep the conversation running while they execute. The family also flips the declaration default — function calls run `NON_BLOCKING` unless declared otherwise — so synchronous tools are explicitly declared `BLOCKING` on `gemini-3.8-live` to keep the model waiting for their results. `gemini-3.8-live-extended-thinking` accepts only `NON_BLOCKING`; synchronous tools there can't pause the conversation, and a warning is logged.
