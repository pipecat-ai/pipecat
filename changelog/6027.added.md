- Added `video_in_sources` to `TransportParams`, so a transport captures the user's video without an `on_client_connected` handler. List the sources to capture, each with its own `VideoInSourceParams(framerate=...)`, and `DailyTransport` captures them from each participant as they join, and `SmallWebRTCTransport` when the peer connects. `VideoInSourceParams(on_request_only=True)` passes on only the frames that answer a `UserImageRequestFrame`. Sources not listed are still captured only when the application asks, as before. Other transports log a warning and ignore `video_in_sources`.
  ```python
  DailyParams(
      video_in_enabled=True,
      video_in_sources={
          "camera": VideoInSourceParams(framerate=1),
          "screenVideo": VideoInSourceParams(framerate=1),
      },
  )
  ```
