- Fixed the assistant aggregator running inference before every function call in a batch had started. A handler that finished without yielding to the event loop, first in the batch, delivered its result before its siblings were announced, so the LLM ran with the rest of the batch still `IN_PROGRESS` and tended to re-issue those calls. The sequential runner (`run_in_parallel=False`) ran one inference per call for the same reason. Every call in a batch is now announced before any of its handlers runs.
