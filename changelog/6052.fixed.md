- `PipelineWorker` can now be cancelled while an `EndFrame` or `StopFrame` is held up in the pipeline. The `CancelFrame` from `cancel()`, an idle timeout, a fatal error or the runner's SIGINT handler used to wait behind the ending frame and was never delivered, so the worker never finished. It now overtakes the ending frame and is bounded by `cancel_timeout_secs` like any other cancel.
