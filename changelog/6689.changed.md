- Changed `DailyRESTHelper.get_token()` to respect `exp` and `is_owner` set in `params` instead of silently overwriting them. `expiry_time` and `owner` now default to `None`; an explicit argument wins over the value in `params`, and the value in `params` wins over the default (1 hour and owner, same as before). Callers passing no `params` get the same token as before.
