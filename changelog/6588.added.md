- Added `WaitReassuranceLLMExtension`, an LLM extension that keeps the conversation from going silent while the user waits on long-running background work: an asynchronous function call (`cancel_on_interruption=False`), or work delegated to an `LLMWithBackend` backend. Attached with `LLMService(extensions=[WaitReassuranceLLMExtension()])` on a text LLM:
  - it adds its `instruction` to the LLM's system instruction, and sets the user aggregator's waiting timeout to its `interval_secs`;
  - once nothing has been said for that long with work in flight, it appends a short developer `prompt` to the conversation and runs the LLM, which says one short sentence in its own words, shaped by what the user asked for, or answers with the `silent_mark` to say nothing;
  - a reply opening with the mark is dropped before anything downstream or any observer sees it, nothing is recorded in the context, and the decision is broadcast as an `LLMMarkerResponseFrame` of kind `silent`, on which the user aggregator starts the interval over. The RTVI observer sends it as `bot-llm-marker` to clients that asked for marker reports, and a scripted eval asserts it with `event: llm_marker` and `marker: silent`.
