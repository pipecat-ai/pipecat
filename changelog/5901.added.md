- `expand_percentages()` now returns the transform, like `expand_numbers()`, and takes a `read_trailing_zeros` option, with a matching `percentage_trailing_zeros` option on `VoiceFormatter`. When set, a percentage's fraction is read one digit at a time like `expand_numbers`, so "1.10%" reads as "one point one zero percent". The default is unchanged ("1.10%" still reads as "one point one percent").
