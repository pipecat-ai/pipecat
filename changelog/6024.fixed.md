- `OpenAIRealtimeLLMService` and `AzureRealtimeLLMService` no longer go silent for the rest of a session after a connection problem:
  - An error event is reported and the service keeps reading later server events.
  - A socket the server closes, a failed send on a live session and a connection that cannot be opened mark the service unusable, so failover and `ProcessorUnusablePolicy` act on it.
