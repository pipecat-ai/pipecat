- `pipecat init` now offers LiveKit as a web transport (`-t livekit`). The generated bot adds `LiveKitParams` to its transport params, `.env.example` lists the `LIVEKIT_URL`, `LIVEKIT_API_KEY` and `LIVEKIT_API_SECRET` credentials, and generated React and vanilla JS clients connect through `@pipecat-ai/livekit-transport`. Run the bot with `uv run bot.py -t livekit`.
