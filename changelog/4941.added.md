- Added an `http_client` parameter to `OpenAITTSService` and Whisper-based STT
  services (`BaseWhisperSTTService`, `OpenAISTTService`, `GroqSTTService`), so a
  custom `httpx.AsyncClient` — e.g. one with a raised request timeout for
  high-latency endpoints — can be used for API requests.

- Added `BaseWhisperSTTService.create_client()`, a public override point for
  constructing the `AsyncOpenAI` client, matching
  `BaseOpenAILLMService.create_client()`.
