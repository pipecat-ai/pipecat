- Fixed eval harness speech failures becoming scripted assertion timeouts, and required measurements passing without a value. Simulation response latency now uses client-observed input delivery and text/audio response receipt independently for each modality.
- Added optional target audio-support verification through `EvalSessionParams(require_audio_support=True)`. Targets advertise their configured eval transport directions before the handshake; existing clients remain compatible with older targets by default.
- Untagged streaming transcripts whose audio origin is ambiguous after an interruption now produce a harness error instead of being used as evidence for a later reply.
- Speech-service failures during the handshake now stop startup without being classified as target connection failures. Simulation results retain the machine-readable run `failure_kind` so callers can distinguish these causes.
