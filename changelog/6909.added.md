- Added an `on_node_entered` event to `FlowManager`, called each time the flow enters a node with a `NodeEntered`: the node, the node it left, the function that caused the move, and the `metadata` of the node and of that function. Handlers run in order before the node's LLM response starts, so they must be fast. `FlowManager` is now a `BaseObject` and has its members (`name`, `id`, `event_handler`, `add_event_handler`, `remove_event_handler`, `task_manager`, `setup`, `create_task`, `cancel_task`, `cleanup`), and the private `FlowManager._set_node` takes a keyword-only `via`.
