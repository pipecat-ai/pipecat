- Added `SarvamHttpSTTService`, a segmented HTTP sibling of the WebSocket
  `SarvamSTTService` that transcribes each speech segment through Sarvam's
  synchronous REST speech-to-text API (Saaras v3/v4). Its `run_stt()` yields
  the transcription inline, so it can back the eval harness's bot-audio
  transcriber: `judge.transcription` now accepts `service: sarvam`, giving
  audio-mode evals a transcriber that handles Indian languages and
  Hindi/English code-mix.
