- Added `SarvamHttpSTTService`, which sends each VAD speech segment to Sarvam's REST speech-to-text API (`saaras:v4` by default, or `saaras:v3`) and yields the transcription from `run_stt()`. It takes the same `mode` and `keyterms` options as `SarvamSTTService`, and sends a segment longer than the API's 30-second limit as consecutive pieces whose transcripts are joined.

  ```python
  stt = SarvamHttpSTTService(
      api_key=os.getenv("SARVAM_API_KEY"),
      settings=SarvamHttpSTTService.Settings(language=Language.HI_IN),
  )
  ```
