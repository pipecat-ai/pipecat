- Added `SarvamHttpSTTService`, which sends each VAD speech segment to Sarvam's REST speech-to-text API (`saaras:v4` by default, or `saaras:v3`) and yields the transcription from `run_stt()`. `mode` applies to `saaras:v3` only.

  ```python
  stt = SarvamHttpSTTService(
      api_key=os.getenv("SARVAM_API_KEY"),
      settings=SarvamHttpSTTService.Settings(language=Language.HI_IN),
  )
  ```
