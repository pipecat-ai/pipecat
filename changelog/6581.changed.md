- The `aic` extra now requires `aic-sdk~=3.4.0`, which uses core SDK 0.26.0 and model file version 8. `AICQuailVADAnalyzer` now defaults to `vad-ms-2.1-xxs-16khz`, and `AICTytoObserver` now defaults to Tyto 1.2, `tyto-1.2-l-16khz`. The SDK cannot download a model that has no version 8 file, such as `quail-vf-2.2-l-16khz`, `tyto-1.1-l-16khz` or `vad-2.1-xxs-16khz`. If you set `model_id` yourself, change to a current model, for example `quail-vf-2.3-l-16khz`. See https://artifacts.ai-coustics.io/ for the available models.
