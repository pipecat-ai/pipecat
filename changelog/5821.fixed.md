- Fixed `GoogleLLMService` (and `GoogleVertexLLMService`) failing with a 400 (`Requests ending with a model turn are not supported.`) on newer Gemini models, such as the default `gemini-3.6-flash`, when the context ends with an assistant message. This happens when a tool handler speaks filler with `TTSSpeakFrame` before its result arrives. A minimal `"."` user turn is now appended to the request in that case, for every model not known to continue a trailing model turn; the stored context is unchanged.
