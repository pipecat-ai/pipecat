- Added `WaitReassurance`, a processor placed after the LLM (a text `LLMService` or an `LLMWithBackend`) that keeps the conversation from going silent while the user waits on work in flight: an asynchronous function call, or a task delegated to a backend. Once nothing has been said for `interval_secs`, it appends a developer `prompt` to the conversation and runs the LLM, which says one or two short sentences in its own words, shaped by what the user asked for, or replies with the `silent_mark` to say nothing, which the processor drops unspoken.
