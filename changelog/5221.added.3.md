- Added `JobParams` and `JobGroupParams`, which carry everything a job dispatch needs in one object: `name`, `payload`, `timeout`, plus `cancel_on_error` for groups and `label` / `cancellable` for how the work presents to a client UI. Pass one to `job(...)`, `job_group(...)`, `request_job(...)`, or `request_job_group(...)`:

  ```python
  job_id = await ui_jobs.request_job_group(
      "wikipedia",
      "news",
      params=JobGroupParams(payload={"query": query}, label=f"Research: {query}"),
  )
  ```
