- Fixed `OpenAILiveLLMService` sessions failing to start when a tool schema
  contains a float. The Live API rejects float literals anywhere in a
  delegated tool schema with `Invalid AVAS session_data: Type is not JSON
  serializable: decimal.Decimal`, which names neither the tool nor the field.
  Whole floats are now converted to the equivalent int and fractional values
  are dropped with a warning.
