- `UIWorker` can now use a classifier for small decisions about the screen instead of a full LLM turn. A classifier is fast and answers one fixed question: `which_element("the checkout button")` returns the element on screen the user means, and `should_respond(event)` says whether a UI event deserves a reply. Pass a `classifier`, for example a `JevClassifier`. If you don't, the worker's own LLM answers those questions through an `LLMClassifier`, which works but is slower. There is also `say(text)`, which makes the bot say something through the pipeline's TTS without an LLM turn.

  ```python
  class ShopWorker(UIWorker):
      @ui_event("nav_click")
      async def on_nav(self, message):
          if await self.should_respond(message):
              await self.say("You have two items. Want me to check out?")

      @tool
      async def press(self, params, description: str):
          ref = await self.which_element(description)
          if ref:
              await self.click(ref)
          await params.result_callback("done" if ref else "not found")


  worker = ShopWorker("ui", llm=OpenAILLMService(api_key=...), classifier=JevClassifier(api_key=...))
  ```
