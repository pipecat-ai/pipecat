- `UIWorker` takes a `classifier` and asks it the small questions about the screen without an LLM turn: `should_respond(event)` says whether a UI event calls for the assistant to speak, and `which_element(description)` picks the element the user means from the snapshot. Without a classifier the worker's `llm` answers through an `LLMClassifier`; a `JevClassifier` answers in about a tenth of a second with a calibrated probability. `say(text)` has the pipeline speak a line through its TTS.

  ```python
  class ShopWorker(UIWorker):
      @ui_event("nav_click")
      async def on_nav(self, message):
          if await self.should_respond(message):
              await self.say("You have two items. Want me to check out?")

      @tool
      async def press(self, params, description: str):
          ref = await self.which_element(description)
          if ref:
              await self.click(ref)
          await params.result_callback("done" if ref else "not found")


  worker = ShopWorker("ui", llm=OpenAILLMService(api_key=...), classifier=JevClassifier(api_key=...))
  ```
