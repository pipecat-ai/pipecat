- Added `RimeRealtimeLLMService` for Rime Prism speech-to-speech conversations, with tools (including intermediate results), runtime settings updates such as handoffs, Prism tool fillers, speech speed, interruption rules (a minimum word count, interrupting phrases, and acknowledgment phrases that don't interrupt), token usage metrics, and optional audio discard. Use it with the standard `LLMContextAggregatorPair`. Prism history is append-only, so after the opening, ask for a reply with `LLMMessagesAppendFrame(run_llm=True)`. Install it with the `rime-realtime` extra, which requires `rimelabs-sdk>=0.1.0a31`.
