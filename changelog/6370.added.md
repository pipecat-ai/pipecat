- Added `RimeRealtimeLLMService` for Rime Prism speech-to-speech conversations, with tools (including intermediate results), runtime settings updates such as handoffs, Prism tool fillers, token usage metrics, and optional audio discard. Use it with the standard `LLMContextAggregatorPair`. Install it with the `rime-realtime` extra, which requires `rimelabs-sdk>=0.1.0a29`.
