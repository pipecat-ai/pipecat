- Added `RimeRealtimeLLMService` for Rime Prism speech-to-speech conversations, with tools (including intermediate results), runtime settings updates such as handoffs, Prism tool fillers, speech speed, interruption rules (a minimum word count, interrupting phrases, and acknowledgment phrases that don't interrupt), token usage metrics, and optional audio discard. To ask for a reply mid-conversation, use `LLMMessagesAppendFrame` with `run_llm=True`. Install it with the `rime` extra.
