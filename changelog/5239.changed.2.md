- `AICQuailVADAnalyzer` now defaults `model_id` to `vad-2.1-xxs-16khz`. The previous default, `quail-vad-2.0-xxs-16khz`, is not published for the model version `aic-sdk` 3.0 requires, so pinning it raises `ModelDownloadError` ("missing compatible version v6"). Callers who set `model_id` explicitly need a model published for that version; see https://artifacts.ai-coustics.io/.
