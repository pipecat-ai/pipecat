- Added the RTVI `flow-node-entered` message, which tells a client each time a Pipecat Flows conversation enters a node, so a client UI can follow the flow. Its data is the node, the node the flow left, the function that moved it there, their metadata and, for a node of a subflow, the node that runs the subflow. Clients of RTVI protocol 2.4.0 or later receive it, and the RTVI protocol version is now 2.4.0. In the pipeline it is an `RTVIFlowNodeEnteredFrame`.
