- Added `OpenAILiveLLMService`, a speech-to-speech service for the OpenAI Live API (`gpt-live-1`). The live model is full-duplex — it listens and speaks at the same time and handles being interrupted itself — and delegates search, reasoning and tool use to a backend model while the conversation continues. Both delegation modes are supported: `OpenAILiveLLMService.ResponsesDelegation` lets OpenAI host the backend (Responses API) model, with its function calls executed by the pipeline's registered tool handlers; `OpenAILiveLLMService.ClientDelegation` runs any Pipecat LLM service as the backend through a `BackendLLMWorker`. See `examples/realtime/realtime-openai-live-responses-delegation.py`, `examples/realtime/realtime-openai-live-client-delegation.py`, and `examples/realtime/realtime-openai-live-client-delegation-speech.py` for a backend that chooses what the user hears.

- Added `BackendLLMWorker`, `BackendOutput` and `run_backend_job()` (`pipecat.workers.llm`): a worker that runs any LLM service, with its own context and multi-step tool calling, as the backend a frontend conversational model delegates work to. Everything the backend produces reaches the frontend as a `BackendOutput` saying what it is and whether the user may hear it; pass `transform_output` to decide that per output, or to rewrite the text on its way out. `OpenAILiveLLMService` uses it for client delegation, and any frontend can delegate to the same worker from a tool — see `examples/multi-worker/backend-llm/backend-llm-cascade-frontend.py` for a cascade frontend and `backend-llm-realtime-frontend.py` for a speech-to-speech one.
