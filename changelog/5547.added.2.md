- Added a `truncation` field to the OpenAI Realtime `SessionProperties`, which sets what the server does once a long session outgrows the model's input token limit. By default it drops the oldest messages, only as many as each response needs. `TruncationRetentionRatio` drops more at once so truncation happens less often and more input stays in the prompt cache, which OpenAI recommends for lowering the cost of long sessions; `"disabled"` returns an error instead of truncating.
