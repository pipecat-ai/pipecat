- ⚠️ `get_llm_invocation_params()` on LLM adapters is now async, so every LLM service can fetch the files a provider needs while building its request. Code that calls it must `await` it, and a custom adapter must define it with `async def`; one that defines it as a sync method gets a `DeprecationWarning` when the class is defined. `AWSNovaSonicLLMService.get_setup_params()` is now async as well.
