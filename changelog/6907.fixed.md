- Fixed `FastAPIWebsocketTransport` logging `exception while closing the websocket: ` (with an empty message) at ERROR when the peer had already disconnected before the transport closed the WebSocket. This is common with uvicorn's websockets-sansio backend, the default since uvicorn 0.50. The `WebSocketDisconnect` raised by the close is now logged at DEBUG with its close code; other close errors stay at ERROR and include the exception class name.
