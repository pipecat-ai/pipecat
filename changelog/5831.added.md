- Added `RunnerArguments.flow_config`, the Pipecat Flows config a session runs, as YAML or JSON text. A bot whose flow is data loads it with the new `FlowConfig.from_session`, which takes the session's flow and the path of the one the bot ships with, falls back to the file when the session named none, and logs which of the two it ran — so one deployment can serve many flows, and a flow that went missing on the way in can be told from a session that named none.
