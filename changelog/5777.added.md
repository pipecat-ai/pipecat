- Scripted eval scenarios can assert on the turn-completion marker the bot's LLM produced with a new `llm_marker` event and a `marker:` field naming its meaning: `complete`, `short`, `long`, or `incomplete` for either of the last two. The bot reports its markers only when a scenario asks for them, so clients never see them by default.

  ```yaml
  - user: "Let me think about it, hmmm"
    expect:
      - event: llm_marker
        marker: incomplete
  ```
