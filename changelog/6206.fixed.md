- Fixed `AnthropicLLMService` going silent for the rest of a call after one refused turn. After a response stops with `stop_reason="refusal"`, the service now removes the turn that triggered it from the context, as Anthropic's docs ask: the user message(s) plus any tool calls, tool results and thoughts the refused request carried. Only what the refused request actually sent is removed, so a message appended while it was in flight is kept; system messages are left alone.
