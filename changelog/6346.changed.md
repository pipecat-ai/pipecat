- ⚠️ Several stop strategies in one `UserTurnStrategies.stop` list now all have to agree before a user turn ends, because `stop_mode` defaults to `StrategyMode.ALL`. For example, `TurnAnalyzerUserTurnStopStrategy` next to `SpeechTimeoutUserTurnStopStrategy` now ends the turn only once both say the user is done. Pass `UserTurnStrategiesParams(stop_mode=StrategyMode.FIRST)` to end the turn on the first stop strategy that decides, as before. A list with a single stop strategy behaves as before.
