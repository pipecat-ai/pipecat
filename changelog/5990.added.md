- RTVI's `bot-ready` message now includes a `capabilities` object describing what the bot does in the session: `audio_in`, `audio_out`, `video_in`, `screen_in`, `video_out` and `metrics`. Clients can use it to show only the UI that applies, such as hiding the video panels for a voice-only bot. A field the bot can't determine is left out, so the client keeps its default; `screen_in` is known when the transport lists its sources in `video_in_sources`. The RTVI protocol version is now 2.2.0.
  ```json
  "capabilities": {
    "audio_in": true,
    "audio_out": true,
    "video_in": false,
    "screen_in": false,
    "video_out": false,
    "metrics": true
  }
  ```
