- ⚠️ `SonioxTTSService` now defaults to Soniox's `tts-rt-v2` model, with `Bryce` as the default voice. `tts-rt-v2` speaks the same WebSocket API as `tts-rt-v1` but offers a different roster of voices, so a `voice` set explicitly must be one `tts-rt-v2` offers. Soniox removes `tts-rt-v1` on August 31, 2026, after which requests naming it route to `tts-rt-v2` regardless.
