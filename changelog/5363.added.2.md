- Added `token_provider` to `AzureLLMService` and `AzureRealtimeLLMService` for Microsoft Entra ID authentication, so Azure services can run without an API key. `api_key` is now optional, and passing neither credential raises `ValueError`:

  ```python
  from azure.identity.aio import DefaultAzureCredential, get_bearer_token_provider

  llm = AzureLLMService(
      token_provider=get_bearer_token_provider(
          DefaultAzureCredential(), "https://ai.azure.com/.default"
      ),
      endpoint="https://my-resource.openai.azure.com/openai/v1",
  )
  ```
