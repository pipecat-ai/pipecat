- Added `speaker` to `TranscriptionFrame`, `InterimTranscriptionFrame` and `EagerTranscriptionFrame`: the `TranscriptionSpeaker` an STT service's speaker diarization assigned to the text, or `None` without diarization. It holds the provider's `label` (e.g. `"A"`, `"S1"`) and a `number` that counts speakers in the order they first appeared, so it reads the same whatever labels the provider uses. `user_id` always holds the transport participant id, empty when the transport does not identify participants.
