- Added `TypeSafeFlowsLLMService` (`pipecat.flows.typesafe_llm`), an LLM service for Pipecat Flows that generates no text. It speaks written lines per node and per tool as LLM text, and at the end of each user turn asks TypeSafe's Jev, in one request, which of the node's tools the turn calls for and, per argument, whether the caller gave it and which value, then runs that tool so transitions and function-call events work as with an LLM. A tool choice or argument value below a confidence threshold (per service, or per tool) is not acted on: a missing or unclear argument gets asked for with a written line, and a turn matching no tool gets the node's reprompt. Tool and value criteria take spoken examples. `examples/flows/yaml/food_ordering/` now runs on it, with no other LLM.
