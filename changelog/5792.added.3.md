- Added `TypeSafeFlowsLLMService` (`pipecat.flows.typesafe_llm`), an LLM service for Pipecat Flows that generates no text. It speaks written lines per node and per tool as LLM text, and at the end of each user turn asks TypeSafe's Jev, in one request, which of the node's tools the turn calls for and what each argument is, then runs that tool so transitions and function-call events work as with an LLM. A tool missing an argument gets asked for with a written line; a turn matching no tool gets the node's reprompt. `examples/flows/yaml/food_ordering/` now runs on it, with no other LLM.
