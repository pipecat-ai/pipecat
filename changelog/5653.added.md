- Added a `translation` setting to `GeminiLiveLLMService.Settings`, forwarded to the Live API connection as `translation_config`. `GeminiLiveVertexLLMService` inherits it. Set `target_language_code` to a BCP-47 code for the language the model translates into, and `echo_target_language` to control whether the model also produces audio when the target language is the one being spoken. Requires a model that supports translation, and `google-genai >= 2.8.0`, which is where the config arrived; the setting reports that requirement if the installed version is older.
