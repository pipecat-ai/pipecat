- `AWSBedrockLLMService` no longer sends Amazon Nova's `<thinking>...</thinking>` reasoning to TTS. Nova (v1) models write it into the answer text before calling a tool, so voice bots were reading it aloud. A `<thinking>` block at the start of the response, or of any text the model writes between tool calls, is now emitted as `LLMThoughtStartFrame` / `LLMThoughtTextFrame` / `LLMThoughtEndFrame`.
