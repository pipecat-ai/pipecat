- Added `AzureVoiceLiveLLMService`, a speech-to-speech service for Azure's Voice Live API. It supports function calling, caller transcription, Azure's semantic VAD (including the multilingual variant), Azure text-to-speech voices (standard, custom, personal and realtime-native), noise suppression and echo cancellation. Set `turn_detection=None` in `session_properties` to drive turns from transport VAD instead. Voice Live is a separate product from Azure OpenAI Realtime, which `AzureRealtimeLLMService` continues to serve.
