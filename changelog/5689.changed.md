- `BackendLLMWorker` now appends to its LLM's system instruction that it is the backend of a voice assistant: that what it receives comes from the assistant and that it does the parts needing its tools or careful reasoning while the assistant handles the rest of the conversation, that a message with no tool calls is told to the user while text beside tool calls is not, that a message needing nothing from it gets no reply at all, that it reports each result as soon as it has it, through the built-in `report_result` tool when it goes on working, does the newest of several requests first, and acts on the latest of the messages that may arrive while it works. A backend prompt need only say what the backend does.
