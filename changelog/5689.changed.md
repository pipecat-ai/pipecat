- `BackendLLMWorker` now appends to its LLM's system instruction that it is the backend of a voice assistant: that what it receives comes from the assistant and what it writes is told to the user, so it should write only a result or a question it cannot proceed without, never announce or describe what it is doing, do the newest of several requests first and report each result as soon as it has it, and act on the latest of the messages that may arrive while it works. A backend prompt need only say what the backend does.
