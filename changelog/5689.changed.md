- `BackendLLMWorker` now appends to its LLM's system instruction that it is the backend of a voice assistant, which sends it requests and handles the rest of the conversation itself; how the end of its turn decides what the user hears (what it writes in a turn with no tool calls is told to the user, what it writes beside tool calls is a note, the built-in `report_result` tool tells the user something in a turn that goes on working, and the built-in `nothing_to_report` tool stands in for a reply when a request needs nothing from it or only stops or changes its work); and how to take requests that arrive while it works (follow the latest, cancel the tools whose results are no longer wanted, do the newest first, and give each result as soon as it has it). A backend prompt need only say what the backend does.
