- Fixed `GoogleLLMService` failing every request when configured with `gemini-3.7-flash`. Gemini 3 flash models are given the fastest thinking level available as a low-latency default, and 3.7 Flash is the first that rejects `minimal`, so every request came back `400 INVALID_ARGUMENT`. It now gets `low`, the lowest level it accepts. Other Gemini 3 flash models still default to `minimal`, and a model that isn't recognized is assumed to accept it.
