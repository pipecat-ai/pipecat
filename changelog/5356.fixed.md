- Fixed `GoogleLLMService` failing every request when configured with `gemini-3.7-flash`. Gemini 3 flash models are given the fastest available thinking level as a low-latency default, and 3.7 Flash rejects `minimal`, so every request returned `400 INVALID_ARGUMENT`. It now gets `low`, the lowest level it accepts. Other Gemini 3 flash models still default to `minimal`, as do models that aren't recognized.
