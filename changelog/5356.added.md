- Added a warning when a `thinking_budget` is set on a Gemini 3 model. Gemini 3 takes `thinking_level` instead, and whether a budget set alongside it is honored, quietly ignored, or rejected outright varies by model and by backend. The rejection names no field, so the warning is the only signal that the setting may not be controlling thinking. Use `thinking_level` for Gemini 3 and keep `thinking_budget` for the 2.5 series.
