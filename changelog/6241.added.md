- Added `LLMFunctionCallDetectedFrame`, pushed downstream by an LLM service as soon as a streamed response starts calling a function (at most once per response). It arrives in order with the response's `LLMTextFrame`s, so a processor placed after the LLM can tell which text the model wrote after deciding to call a function, for example to keep it from being spoken. Supported by the OpenAI (and OpenAI-compatible), OpenAI Responses, Anthropic, AWS Bedrock, Google Gemini, and SambaNova LLM services. See `examples/function-calling/function-calling-suppress-text-after-call.py`.
