- `pipecat-ai[whisper]` is importable again on Apple Silicon without also installing `pipecat-ai[mlx-whisper]`. `pipecat.services.whisper.stt` imported `mlx_whisper` at module scope on macOS arm64, so a faster-whisper install raised `ImportError: Missing module: No module named 'mlx_whisper'`. `WhisperSTTServiceMLX` already imports it lazily, and the hint about the `mlx-whisper` extra now lives there.
