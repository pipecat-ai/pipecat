- Added `ErrorCategory`, recording why an operation failed — a rejected API key (`AUTHENTICATION`) versus a provider outage (`SERVER`), for example — so error handlers can tell a transient failure from one that will keep recurring until the configuration changes.

    `ErrorFrame` carries it in a new `category` field, and `FrameProcessor.push_error()` accepts it as an argument:

    ```python
    await self.push_error("rejected API key", category=ErrorCategory.AUTHENTICATION)
    ```

    Errors reported without a category are `ErrorCategory.UNKNOWN`, which handlers treat the same way they treated every error before.

    A service classifies an error only when it came from talking to its provider. Failures in application code the service invoked are reported as `ErrorCategory.APPLICATION` instead — a tool handler whose own API call returns 401 leaves the LLM service's health untouched, since its credentials were never in question.
