- Added `RimeV1TTSService` for Rime's WebSocket v1 API, with binary and JSON protobuf envelopes, Coda text lookahead, and context cancellation without reconnecting. Text is sent as sentences by default; pass `text_aggregation_mode=TextAggregationMode.TOKEN` to stream LLM tokens, which Rime accumulates into sentences. Install `pipecat-ai[rime]` to use it.
