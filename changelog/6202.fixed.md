- Fixed `SileroVADAnalyzer` sometimes reporting that the user stopped speaking partway through a word, which could cut off the end of a transcript or close the turn on incomplete audio. The analyzer reset the model's state every five seconds of wall-clock time, and a reset during speech could drop the model's confidence below the threshold. The model now keeps its state for the whole stream, so the result no longer depends on where that timer happened to land.
