- Added `TranscriptionFinalizedFrame`, which an STT service pushes when it confirms a finalization that has no text left to carry: the transcripts before it are complete, as `finalized=True` on a `TranscriptionFrame` would say. The user turn stop strategies (turn analyzer, speech timeout, classifier and external) treat it as a finalized transcript. STT services push it with `STTService._push_transcription_finalized()` after `confirm_finalize()`.
