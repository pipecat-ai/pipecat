- Fixed `KokoroTTSService` completing long contexts "with no audio": kokoro-onnx synthesizes up to 510 phonemes in one model pass, so a long reply's first audio was one full-text inference away (11s+ warm on a CPU-only machine) and blew past the stop-frame timeout, surfacing as an error frame with the audio arriving seconds later. Text is now phonemized once and streamed as punctuation-aware phoneme chunks (`stream_chunk_phonemes`, default 60) joined with kokoro-onnx's own pause lengths, a warm-up synthesis at construction (`warmup`, default on) primes espeak-ng and the ONNX session off the critical path, and `stop_frame_timeout_s` defaults to 10s for this local provider. The `kokoro` extra's kokoro-onnx floor rises to 0.6.0, where the public chunker API first appears.
