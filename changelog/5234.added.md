- Added a `leading_non_speech_characters` parameter to `TTSService`, so a chunk that opens a context with nothing to voice is skipped. Empty by default, so behavior is unchanged unless configured. `CartesiaTTSService` defaults it to the punctuation Cartesia's normalizer discards, since a transcript made only of those normalizes to empty and is rejected — which an LLM can produce by opening a resumed reply with a bare ellipsis.
