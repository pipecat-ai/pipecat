- Added `ModulateSTTService` for Modulate's Velma 2 multilingual streaming STT. The server segments speech into utterances over a persistent WebSocket connection, delivering per-utterance finals with a detected language and word-by-word interim results. Settings support language pinning, speaker diarization, emotion/accent/deepfake signals, PII/PHI tagging, and custom vocabulary. Install with `pip install pipecat-ai[modulate]` and set `MODULATE_API_KEY`.
