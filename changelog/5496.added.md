- Added `GandrTTSService`, a text-to-speech service for the Gandr API at `https://tts.gandr.ai/v1/audio/speech`. The service sends a POST request with a JSON body of `model`, `input`, `voice`, and `response_format`, authenticates with an `Authorization: Bearer` key (a `gnd_` key comes from gandr.ai), and requests `pcm` audio (headerless 16-bit little-endian mono at 24000 Hz) that is resampled to the pipeline sample rate when it differs. Input is capped at 2000 characters. See `examples/voice/voice-gandr.py` for a runnable bot.
