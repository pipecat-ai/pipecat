- Fixed websocket-based services stalling when the peer stops reading. A send waited on the full write buffer until TCP gave up, which could take many minutes, holding up the service's processor and every processor after it with no error or reconnect. Each send through `WebsocketService` is now bounded at 5 seconds; a send that outlasts it drops the connection and fails with `ConnectionClosedError`, so the service's existing reconnect handling takes over. Set `ws_send_timeout` on `WebsocketService` to change the bound, or `None` to disable it.
