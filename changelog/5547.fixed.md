- Fixed `OpenAIRealtimeLLMService` going silent with the `gpt-transcribe` and `gpt-live-transcribe` transcription models. The `session.updated` event OpenAI sends back carries a `languages` field that `InputAudioTranscription` failed to parse, which stopped the service from handling any further server events. `InputAudioTranscription` now ignores transcription fields it doesn't model.
