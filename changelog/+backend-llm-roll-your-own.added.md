- Added `delegate_to_backend()` and `render_transcript_request()` (`pipecat.workers.llm`), the caller side of the `BackendLLMWorker` job contract, so any frontend can run the two-layer split OpenAI Live client delegation uses: a conversational model out front, a heavier model doing the work it hands off. A frontend delegates from a tool — `delegate_to_backend()` puts a request to the worker and streams back each `BackendOutput` as it arrives — and composes that request however it likes: `render_transcript_request()` renders the conversation as a labelled transcript, which is what a frontend whose model hands off without wording a request needs, while a frontend whose model does word one sends it as it stands. See `examples/multi-worker/backend-llm/backend-llm-cascade-frontend.py` for a cascade frontend and `backend-llm-realtime-frontend.py` for a speech-to-speech one.
