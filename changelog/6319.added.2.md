- Added `PipecatToneReader` to expressive conversation (alpha), a processor that reads each transcribed user turn with the Pipecat Tone model and sets the reading on its `TranscriptionFrame`: the user's likeliest emotions and how likely the turn is to be sarcastic, read from the words against the bot's previous reply, or on their own with `read_previous=False`. Place it after the STT service; the model downloads from Hugging Face at start and runs on the CPU. Install it with `pipecat-ai[tone]`. See `examples/expressive-conversation/expressive-conversation-tone.py`.
