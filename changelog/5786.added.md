- Added `LLMMarkerResponseFrame`, pushed by `UserTurnCompletionLLMServiceMixin` when a response ends with the raw text the LLM produced, the marker it read and the markers it recognizes. The RTVI observer sends it as `bot-llm-marker` when `bot_llm_marker_enabled` is on, so the eval harness's `llm_marker` event now carries `raw` and `markers`, and a scripted scenario can check the marker protocol with `marker_first`, `markers` and `text_after` on an `llm_marker` expectation.
