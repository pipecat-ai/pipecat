- Added `examples/transports/transports-websocket-server.py`, showing the
  WebSocket server transport, where the client dials in to the bot rather
  than the bot reaching out. Useful for embedded devices that cannot run a
  browser. Uses `gpt-live-1` for full-duplex conversation, and notes the two
  things that bite people: a serializer is required (the default is `None`,
  and without one every inbound message is silently dropped), and only one
  client is served at a time.
