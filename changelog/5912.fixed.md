- Fixed Flows actions never finishing when the user interrupted a `tts_say` or `function` action before it reached the end of the pipeline. The interruption dropped the frame that ends the action, so `execute_actions()` hung (stalling the node transition for `pre_actions`) and deferred post-actions stopped running for the rest of the session. A `function` action queued behind interrupted speech now still runs, and a `function` action whose handler raises now ends too.
