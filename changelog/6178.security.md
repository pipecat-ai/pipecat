- Error messages no longer carry the credentials they quote. `ErrorFrame` masks any API key, token, signed URL signature, auth header or URL password in its `error` as `[REDACTED]` and keeps the rest of the message, so the ERROR log line, observers such as `ErrorObserver`, `on_error` handlers and RTVI error messages all get the masked text. Previously, for example, a rejected Sarvam STT connection logged the API key (the Sarvam SDK's error prints the request headers), and a file URL the LLM couldn't fetch was logged with its signature.
