- Cut Pipecat's import time by loading heavy third-party dependencies on first
  use instead of at import. NLTK, which reaches `scikit-learn` through its
  classifier backends, now loads inside `match_endofsentence()`, and `fastapi`
  is type-checking-only in `pipecat.runner.types` and `pipecat.runner.utils`.
  `PipelineWorker` warms NLTK on a background thread as the pipeline starts, so
  the opening bot turn doesn't pay the load either. The NLTK `punkt_tab` data
  check, which can hit the network, moves off module import to that warming.

- `LLMContext` and `LLMService` no longer import the OpenAI SDK, so a pipeline
  that talks to another provider no longer loads it. `LLMContext` takes its
  "not provided" sentinel from Pipecat rather than the SDK, and
  `LLMService.adapter_class` defaults to `None`, resolving to `OpenAILLMAdapter`
  at construction. Bots on a non-OpenAI provider save about 230ms of import.

  ⚠️ `LLMService.adapter_class` reads as `None` rather than `OpenAILLMAdapter`
  when a subclass doesn't set it. Use `get_llm_adapter()` to get the resolved
  adapter instance. Code comparing `LLMContext`'s `NOT_GIVEN` against OpenAI's
  by identity needs updating; use `is_given()` instead.

- Added `pipecat.utils.types`, home of the `NOT_GIVEN` sentinel now shared by
  settings, `LLMContext` and anything else needing "this value was not
  provided", together with `is_given()` and `assert_given()`. Provider SDKs keep
  their own equivalents, translated at the adapter boundary. All four names
  remain importable from `pipecat.services.settings`, and the sentinel and
  `is_given()` from `pipecat.processors.aggregators.llm_context`.

  ⚠️ The private `pipecat.services.settings._NotGiven` is now the public
  `pipecat.utils.types.NotGiven`. Import it under its new name, or from
  `pipecat.services.settings`, which re-exports it.
