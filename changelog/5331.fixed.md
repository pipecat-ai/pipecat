- Fixed word-level tracking breaking for a sentence whose synthesis tags come from the LLM itself, e.g. an LLM prompted to emit `<spell>1234</spell>` with `SkipTagsAggregator` keeping the tagged block intact. Tags written by the LLM are part of its text, so the text shown to the user and the text sent to the TTS were identical and the entire sentence was treated as one untrackable unit: it reported no progress until it had finished speaking, and its words reached the conversation context only as a single block at the end. Only the tagged span is now treated that way, so every word around it emits its own `TTSTextFrame` and `AggregatedTextProgressFrame`. Applies to both SENTENCE and TOKEN text aggregation. Tags inserted by a text transform were never affected, since those reach the TTS without entering the user-facing text.
