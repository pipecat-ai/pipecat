- Added a machine-readable specification of the RTVI protocol: an AsyncAPI 3.0 document for each protocol version, shipped in the package at `pipecat/processors/frameworks/rtvi/spec/<version>/rtvi.asyncapi.json`. It lists every message a client sends and the server sends, with each field's schema and description, an example, the setting that turns the message on, the lowest client version that receives it, and the rules the server follows across messages, such as which message answers which. Client libraries can generate their protocol code from it, and anyone can build an RTVI client or server from it. The [RTVI reference](https://docs.pipecat.ai/api-reference/standards/rtvi/latest) is generated from it.
