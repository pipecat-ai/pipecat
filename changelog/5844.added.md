- Added `bulbul:v4-flash` support to `SarvamTTSService` and `SarvamHttpTTSService`. The model supports `pitch` and `loudness`, which `bulbul:v3` ignores, and ignores `temperature`, which Sarvam pins to 0.6. It has its own speaker catalogue — pass a speaker from Sarvam's docs, or omit `voice` to get `shubh_en_narration_gentle`. Access is gated per subscription; without it Sarvam answers with HTTP 422.
