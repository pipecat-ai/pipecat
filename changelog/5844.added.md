- Added `bulbul:v4-flash` support to `SarvamTTSService` and `SarvamHttpTTSService`. The model has its own speaker catalogue — 224 wire names such as `shubh_en_narration_gentle` (the default) and `ritu_hi_edtech`, exposed as `SarvamTTSSpeakerV4Flash`; the `bulbul:v3` names are not accepted. It supports `pitch` (-0.5 to 0.5) and `loudness` (0.1 to 2.5), which `bulbul:v3` ignores, and ignores `temperature`, which Sarvam pins to 0.6. Access is gated per subscription; without it Sarvam answers with HTTP 422.
