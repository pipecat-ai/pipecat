- Added `ClefClassifier`, which answers classifier questions with Cloudflare's Clef on Workers AI. Pass `model="clef-flash"` for the faster model. It takes a Cloudflare account ID and API token, and several classifiers can share one `ClefClient`. A choice question can have at most 255 options (`CLEF_MAX_CHOICE_OPTIONS`). Install with `uv add "pipecat-ai[cloudflare]"`.

  ```python
  classifier = ClefClassifier(
      account_id=os.getenv("CLOUDFLARE_ACCOUNT_ID"),
      api_key=os.getenv("CLOUDFLARE_API_KEY"),
  )
  results = await classifier.yes_no(
      "Hi, you've reached Dana. Leave a message.",
      {"voicemail": YesNoQuestion(instructions="is this a voicemail?")},
  )
  ```
