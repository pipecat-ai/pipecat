- Added `HumeAudioClassifier` in `pipecat.classifiers.hume.audio_decisions.classifier`, a classifier backed by Hume's Audio Decisions API. It answers yes/no, choice and score questions about 5 seconds to 5 minutes of audio, sent as 16 kHz mono WAV, with the state as the clip's context. It opens its connection to Hume when it's set up, so the first clip of a call doesn't wait on a new connection. Install it with `pipecat-ai[hume]`, which now includes `httpx`.
