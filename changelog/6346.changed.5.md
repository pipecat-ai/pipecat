- ⚠️ `WakePhraseUserTurnStartStrategy` now starts turns on its own: once awake, it starts a turn when the user starts speaking or a final transcription arrives, which covers speech VAD missed. Use it as the only start strategy, `start=[WakePhraseUserTurnStartStrategy(...)]`. To combine it with other start strategies, such as `MinWordsUserTurnStartStrategy`, put them in a `StrategyMode.ALL` list. Putting it first in a `FIRST` list still keeps the strategies after it from seeing frames until it hears the wake phrase, with a `ProcessFrameResult` deprecation warning, but once awake it starts turns itself, so those strategies no longer decide.
