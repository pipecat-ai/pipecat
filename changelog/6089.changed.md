- `SonioxSTTService` and `SonioxTTSService` now report the errors Soniox sends in-stream with an `ErrorCategory` derived from the HTTP status code the message carries, so an exhausted balance arrives as `quota` and a rejected key as `authentication` rather than `unknown`. The error frames `SonioxTTSService.run_tts` yields on a failed send or connect carry the exception, so those are classified too.
