- `SarvamTTSService` and `SarvamHttpTTSService` now default to `bulbul:v4-flash`, Sarvam's low-latency model, with the voice `shubh_en_narration_gentle`. Set `Settings(model="bulbul:v3")` to keep v3: it's needed for a v3 voice such as `priya`, and for the extension languages v4-flash doesn't serve (Bodo, Konkani, Maithili, Manipuri, Nepali, Sanskrit, Santali, Sindhi and Urdu).
