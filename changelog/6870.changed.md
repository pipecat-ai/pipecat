- `SarvamTTSService` and `SarvamHttpTTSService` now default to `bulbul:v4-flash`, the model Sarvam recommends, with the voice `shubh_en_narration_gentle`. A service given a `bulbul:v3` voice such as `priya` but no model stays on `bulbul:v3` and logs a warning, since v4-flash refuses v3 voices. Set `Settings(model="bulbul:v3")` to keep v3 explicitly: it's also needed for the extension languages v4-flash doesn't serve (Bodo, Konkani, Maithili, Manipuri, Nepali, Sanskrit, Santali, Sindhi and Urdu).
