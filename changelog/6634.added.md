- Added `text_metadata_keys` to `TTSService`, naming the `Frame.metadata` keys a TTS service carries from the text it receives (`LLMTextFrame`, `AggregatedTextFrame`, `TTSSpeakFrame`) to the frames it builds from it: the aggregated sentences and the `TTSTextFrame` and `AggregatedTextProgressFrame` frames that report the text as spoken. This lets an application tie spoken text back to its source, such as a message ID. Text whose values for these keys differ never shares a sentence.
