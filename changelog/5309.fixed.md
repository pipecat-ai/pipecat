- Fixed `OpenAIResponsesLLMService` silently dropping a reply that the API sent whole rather than streamed. A short message can arrive in a single `response.output_text.done` with no `response.output_text.delta` events before it; only the deltas were pushed, so that reply reached neither the transcript nor TTS and the bot said nothing. Most visible on replies that are naturally brief, such as announcing that an async tool call has finished.
