- ⚠️ Local evals run through the dev runner: start the bot with `python bot.py`, and `pipecat eval run` connects to `ws://localhost:7860/ws` by default. Each scenario gets a fresh `bot()` and pipeline. A `--bot-url` without the `/ws` path is rejected; add `/ws` to it.
  - `pipecat eval suite` spawns bots without `-t eval`, connects to their `/ws` route, and stops each bot as soon as its run ends. A manifest whose `spawn:` still passes `-t eval` keeps working.
  - The harness waits up to 60 seconds for a bot's `bot-ready`, up from 10.
  - The harness ends the bot's session when a run finishes, whatever the bot's `on_client_disconnected` handler does.
