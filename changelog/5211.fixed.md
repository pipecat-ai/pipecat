- Fixed `PipelineWorker` hanging forever when a finalize frame (`EndFrame`/`StopFrame`) never reaches the pipeline sink. Previously only `CancelFrame` had a bounded wait (`cancel_timeout_secs`); now all finalize frames share the same timeout, so a processor that drops or blocks the terminal frame no longer deadlocks the worker's push-queue loop (and the subsequent `CancelFrame` it may enqueue) until external task cancellation.
