- Added `GoogleInteractionsLLMService`, an LLM service for the Gemini Interactions API. It sends the full context each turn with `store=False`, so Google keeps no conversation state. Import it from `pipecat.services.google.interactions.llm`; it needs `google-genai` 2.0.0 or later.
  - It takes the same settings as `GoogleLLMService`, so switching is a change of class. `top_k`, `frequency_penalty`, `presence_penalty` and a thinking budget have no Interactions API field and are ignored with a warning; thinking is set by `thinking_level`.
  - Thought signatures are stored in the context the same way `GoogleLLMService` stores them, so a conversation can move between the two services mid-call, including one with function calls.
  - Supports streaming text, function calls (parallel and sequential), thought summaries, images, audio and documents, built-in Gemini tools passed as `tools`, `run_inference()` with a `response_schema`, and token usage metrics.
  - A completed response with no text and no function call logs a warning and pushes a non-fatal `ErrorFrame`, so the application can react instead of the bot going silent.
  - See `examples/voice/voice-google-interactions.py`, `examples/function-calling/function-calling-google-interactions.py`, `examples/vision/vision-google-interactions.py` and `examples/thinking/thinking-functions-google-interactions.py`.
