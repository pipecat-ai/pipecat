- ⚠️ A function call that exceeds `function_call_timeout_secs` (or a per-tool `timeout_secs`) is now cancelled instead of being left to run. Its handler is thrown an `asyncio.CancelledError` so cancel-aware handlers run their cleanup, and the call settles as cancelled through the same path used for interruptions and LLM-requested cancellation: a `FunctionCallCancelFrame` and the `on_function_calls_cancelled` event. Previously the deadline only reported the call as finished with an empty result while the handler kept running, so its side effects still landed and its eventual result was discarded. The deadline covers the handler's own execution; work a handler spawns into a task of its own is not cancelled with it.
