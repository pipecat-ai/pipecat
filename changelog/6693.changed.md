- A function call cancelled before it returns, by an interruption or a timeout, is now settled in the context with a result saying its outcome is unknown and its action may already have taken effect, instead of a bare `"CANCELLED"`. The LLM no longer tells the user that an action which went through did not happen, or calls the tool again on its own. The OpenAI Realtime, OpenAI Live, Grok and Inworld services send the same result to their APIs. The text is available as `async_tool_messages.CANCELLED_CALL_RESULT`; code that compared a tool result with `"CANCELLED"` should compare with that constant, or check for the `"CANCELLED"` prefix.
