- `DeepgramSTTService`, `DeepgramSageMakerSTTService`, `SonioxSTTService`, `XAISTTService` and `SmallestSTTService` now report diarization speakers: with diarization enabled, a final result is emitted as one `TranscriptionFrame` per contiguous speaker run, each with the provider's speaker in `speaker_label`. Only the last frame of a result is `finalized`, so the turn does not end before every run has arrived. `SmallestSTTService` requests word timestamps when `diarize` is on, since they carry the speakers.
