- Deprecated `FunctionCallUserMuteStrategy`, which will be removed in 2.0.0. Constructing one now emits a `DeprecationWarning`. Register the tool with `@tool_options(cancel_on_interruption=False)` instead (or `register_function(..., cancel_on_interruption=False)`): the call runs to completion across an interruption, and the user stays free to speak. Muting is the coarser tool: it applies to every function call, so the user is silenced for as long as the slowest one takes, and their speech is dropped rather than deferred.
