- Added `ZoomAISTTService`, streaming speech-to-text with Zoom Scribe Live. Install it with `pipecat-ai[zoom-ai]`. `pipecat init` offers it as "Zoom AI".
  - Scribe's voice activity detection ends each turn, so the service recommends `ExternalUserTurnStrategies`. `Settings.silence_duration_ms` (default 350, tuned for voice agents) sets how much silence ends a turn.
  - `Settings.diarization` (off by default) labels speakers; the labels are in `TranscriptionFrame.result`.
