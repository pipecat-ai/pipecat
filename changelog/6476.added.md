- `GeminiLiveLLMService` applies system instruction and tool changes to a live Gemini 3.8 Live session with a `context_update`, without reconnecting: `LLMSetToolsFrame`, `system_instruction` settings updates, and tool changes in an updated context. A first context that brings its own tools updates the open session instead of reconnecting. When a resumed session is ready, whichever of the instruction and tools differ from its original setup are re-sent. Needs `google-genai>=2.33.0`, which the `google` extra now requires outside Python 3.13 on Linux. On other models, tool changes take effect on the next session (a mid-session `LLMSetToolsFrame` logs a one-time warning) and `system_instruction` settings updates aren't applied.
