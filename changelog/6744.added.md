- Added reporting for a reply the provider's content filter cut short. `BaseOpenAILLMService` now reads `finish_reason` on the stream and pushes an error with `ErrorCategory.CONTENT_FILTERED` (carrying the OpenAI SDK's `ContentFilterFinishReasonError`) after the text released so far, so apps can tell a filtered turn from a finished one and interrupt or count it the same way they already do for a blocked request. `run_inference()` raises the same exception instead, since it has no frame pipeline to report through.
