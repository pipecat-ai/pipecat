- Added `PalabraSTTService`, a streaming speech-to-text service backed by Palabra's Realtime Speech-to-Text WebSocket API. A VAD stop finalizes the pending segment. `Settings` supports `language`, `translate_languages` (finalized segments are also pushed as `TranslationFrame`s), `enable_filler_filter`, `finalization_mode` and `finalization_timeout`. Install with `pip install "pipecat-ai[palabra]"`.

- Added `PalabraTTSService`, a streaming text-to-speech service backed by Palabra's Realtime TTS WebSocket API, available in the `eu` and `us` regions. Each sentence is one Palabra generation, and interruptions send Palabra's `cancel` command instead of reconnecting. `Settings` supports `voice`, `model`, `language`, `speed` and `deaccent_strength`.

- Added `PalabraTranslationService`, a speech-to-speech translation service backed by Palabra's Streaming API. It replaces the STT, LLM and TTS trio with a live interpreter: it pushes the source transcription, a `TranslationFrame` per target language and the translated speech as `TTSAudioRawFrame`s. `Settings` supports `language`, `target_languages`, `generate_speech`, `voice`, `voice_cloning`, `translate_partials`, `silence_threshold`, `audio_destinations` (plays each target language's speech on its own transport destination) and raw task option overrides; changes are applied live without reconnecting. `interrupt()` drops the phrase being spoken and `speak()` injects text into the pipeline.
