- `UIWorker` answers a voice LLM's questions about the screen as jobs, so the voice LLM never sees the page: `find` names the element a description means, `check` says whether something is true of the screen, `select` lists the elements matching a description, `act` finds an element and clicks, scrolls to, highlights, selects or fills it, and `elements` lists what is on screen. `screen_tools(worker_name)` gives the voice LLM the matching tools in one line.

  ```python
  context = LLMContext(tools=[*screen_tools("ui")])
  ```
