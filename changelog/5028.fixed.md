- Fixed `GeminiLiveLLMService` crashing with WebSocket error 1007 when seeding a session from a context containing tool calls (e.g. after a multi-agent handoff or a reconnect). Gemini Live only accepts text and media content, so the new `GeminiLiveLLMAdapter` summarizes function calls and their responses as text.

  ⚠️ `GeminiLiveLLMService` now uses `GeminiLiveLLMAdapter` rather than `GeminiLLMAdapter`, so any hand-crafted `LLMSpecificMessage`s aimed at it need `llm="gemini-live"` instead of `llm="google"`. We recommend you use `LLMService.create_llm_specific_message()`, which picks the right value for you.
