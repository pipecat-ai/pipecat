- `DeepgramFluxSTTService` now reports Deepgram's reason when it refuses the connection, so an out-of-range setting or a bad API key is named in the error (for example, `Deepgram refused the connection (HTTP 400): eot_threshold must be between 0.5 and 1, inclusive.`) rather than a bare `server rejected WebSocket connection: HTTP 400`. The `on_connection_error` event receives the same message.
