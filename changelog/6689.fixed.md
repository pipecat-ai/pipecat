- Fixed `DailyRESTHelper.get_token()` sending `eject_at_token_exp: false` on every token. Daily treats any token-level eject setting, even `false`, as an override of the room's `eject_at_room_exp`, so rooms set to eject at expiry never ejected these participants. The argument now defaults to `None` and is left out of the request unless you set it, or set it in `params`. Pass `True` or `False` to override the room setting.
