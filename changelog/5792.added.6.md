- Added `TypeSafeFlowsRouter` (`pipecat.flows.typesafe_flows_router`), a processor that sits in front of a text LLM in a Flows pipeline and runs the node's tools on TypeSafe judgments. At the end of each caller turn it asks, in one request, which tool the turn calls for, what each argument is, and whether the caller said more than what was asked. When every answer is sure (0.9 by default, per tool overridable) it runs the tool and speaks the next node's written line itself; when the tool is clear but something is less sure it runs the tool and lets the LLM speak; otherwise the turn goes to the LLM untouched, tools included. `examples/flows/yaml/food_ordering/` now runs on it with PhoneLLM (`pipecat-ai/phonellm-alpha-1` on Modal) as the LLM.
