- Added `PipecatSidechat` in `pipecat.turns.sidechat`, a processor that lets a bot in a conversation between several people answer only the turns meant for it, using Pipecat Sidechat, a model that runs on the CPU. It goes between the user aggregator and the LLM: it answers a turn for the bot, answers a question to the room if nobody else speaks for `hold_secs`, and stays quiet otherwise. The turn stays in the context either way. It reads who said what from the tags a diarizing STT service's `speaker_format` writes into each transcript. A bot that isn't an assistant on a call can say what it is and does with `role`, and can list the things people ask it for without its name in `commands`: a turn that contains one is answered whatever the model reads. Experimental: the model and these types are likely to change between releases. Install it with `pipecat-ai[sidechat]`; see `examples/turn-management/turn-management-sidechat.py`.
  - `PipecatSidechatClassifier` in `pipecat.classifiers.sidechat.classifier` answers the model's own questions about a line and the turns before it.
