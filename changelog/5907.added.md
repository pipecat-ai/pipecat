- Added `LLMUserAggregatorParams.empty_user_turn`, an `EmptyUserTurnConfig` for user turns that end with no transcript, such as a cough, background noise, or speech the STT could not recognize. It is on by default, even when `empty_user_turn` isn't passed, and treats two cases differently:

  - Interrupted: the turn cut the bot off. The bot would otherwise stay silent mid-response, so the aggregator appends a developer message (`interrupted_prompt`) and runs the LLM once, and the bot asks the user to repeat or picks up where it left off. On by default.
  - Idle: the bot had finished and was waiting for the user. The conversation isn't stuck, and answering what may be noise would be intrusive, so these turns get no answer unless `idle_prompt` is set.

  ```python
  LLMUserAggregatorParams(
      empty_user_turn=EmptyUserTurnConfig(
          idle_prompt=(
              "The user may have said something, but it was not "
              "recognized. Briefly ask them to repeat it."
          ),
      ),
  )
  ```

  Setting `interrupted_prompt=None` turns off the interrupted case, and `empty_user_turn=None` turns off both. `max_consecutive_recoveries` (default 1) limits how many empty turns in a row get an answer.
