- Added `LLMUserAggregatorParams.empty_user_turn`, an `EmptyUserTurnConfig` for user turns that end with no transcript, such as speech the STT could not recognize. By default, when such a turn interrupted the bot, the aggregator appends a developer message and runs the LLM once, so the bot asks the user to repeat instead of going silent. Pass `empty_user_turn=None` to turn this off.

  An empty turn while the bot was idle is most likely background noise, so by default it gets no answer. To answer it too, set `idle_prompt` to the developer message the LLM should receive in that case:

  ```python
  LLMUserAggregatorParams(
      empty_user_turn=EmptyUserTurnConfig(
          idle_prompt=(
              "The user may have said something, but it was not "
              "recognized. Briefly ask them to repeat it."
          ),
      ),
  )
  ```

  `interrupted_prompt` customizes the message for the interrupted case, and `max_consecutive_recoveries` (default 1) limits how many empty turns in a row get an answer.
