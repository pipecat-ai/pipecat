- Added `HumeAudioClassifier` in `pipecat.classifiers.hume.audio_decisions`, a classifier backed by Hume's Audio Decisions API that hears a clip of the user's speech. Install it with `pipecat-ai[hume]`. As a `PerceptionReader` source, it reads how the user sounded: see `examples/expressive-conversation/expressive-conversation-hume-audio-decisions.py`.
