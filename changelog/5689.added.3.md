- Added `ExternalFunctionCallsStartedFrame`, `ExternalFunctionCallInProgressFrame`, `ExternalFunctionCallResultFrame` and `ExternalFunctionCallCancelFrame`: system frames reporting function calls that ran outside the pipeline (e.g. in a backend worker's pipeline on behalf of a tool), mirroring the pipeline's own function-call frames, which `RTVIObserver` turns into the usual `llm-function-call-*` messages under the per-function report level and nothing else in the pipeline acts on. `LLMWithBackend` reports the backend's calls this way, and so does `OpenAILiveLLMService` client delegation.
