- Added `ExternalFunctionCallFrame`, a system frame reporting a function call that ran outside the pipeline (e.g. in a backend worker's pipeline on behalf of a tool), which `RTVIObserver` turns into the usual `llm-function-call-*` messages under the per-function report level and nothing else in the pipeline acts on. The RTVI function-call messages gain an optional `parent_tool_call_id`, the `tool_call_id` of the call the reported one ran as part of, so a client can show nested calls under the call that caused them. `TwoLayerLLMService` reports the backend's calls this way as children of the `delegate` call, and `OpenAILiveLLMService` client delegation reports them too, as it already did for Responses delegation.
