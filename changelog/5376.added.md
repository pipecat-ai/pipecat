- Added `--ice-servers` to the development runner, along with the matching `PIPECAT_ICE_SERVERS` environment variable, so a bot started through `pipecat.runner.run.main()` can use custom STUN and TURN servers. Entries are bare URLs (`--ice-servers stun:stun.l.google.com:19302`) or JSON objects when a TURN server needs credentials (`--ice-servers '{"urls": "turn:turn.example.com:3478", "username": "user", "credential": "pass"}'`). The runner previously dropped the `ice_servers` parameter that `SmallWebRTCRequestHandler` accepts, so the bot's peer connection was always built with an empty ICE configuration and could only offer host candidates. Configured servers are also returned to clients in the `iceConfig` of the `/start` response, where they take precedence over the public STUN server that `enableDefaultIceServers` returns.
