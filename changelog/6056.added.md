- Added `BaseTransport.capture_participant_video(participant_id, framerate=30, video_source="camera")`, so a bot captures a user's video on demand the same way on Daily, SmallWebRTC and LiveKit. A `framerate` of `0` passes on only the frames that answer image requests, and `None` passes on every frame, which `DailyTransport` now accepts too. Transports that don't receive user video log a warning.
  ```python
  client_id = get_transport_client_id(transport, client)
  await transport.capture_participant_video(client_id, framerate=1, video_source="screenVideo")
  ```
