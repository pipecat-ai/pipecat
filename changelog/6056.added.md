- Added `BaseTransport.capture_participant_video(participant_id, framerate=30, video_source="camera", *, on_request_only=False)`, so a bot captures a user's video on demand the same way on Daily, SmallWebRTC and LiveKit. `on_request_only=True` passes on only the frames that answer image requests, as in `VideoInSourceParams`, and a `framerate` of `None` passes on every frame, which `DailyTransport` now accepts too. Transports that don't receive user video log a warning.
  ```python
  client_id = transport.get_client_id(client)
  await transport.capture_participant_video(client_id, framerate=1, video_source="screenVideo")
  ```
