- Added `BaseWorker.request_cancel_job_group(job_id, reason=...)`, the door for cancellation asked for from outside the worker. It honors the request only for a group dispatched with `JobGroupParams(cancellable=True)` and returns whether it did, so a client UI, an operator endpoint, or anything else reaching in gets the same rule. Cancellation the worker decides on itself, on shutdown, on a timeout, or through `cancel_on_error`, still calls `cancel_job_group()` and is never refused.
