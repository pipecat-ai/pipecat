- Added `text_transforms` to `LLMTextProcessor`, with `add_text_transformer()` and
  `remove_text_transformer()`. The same `(text_type | "*", transform)` pairs a TTS service
  takes can now rewrite each aggregation before it splits toward the TTS, the context and the
  client, so a habit the LLM keeps repeating (emoji, stage directions), a name it should
  not use, or a pattern to redact can be rewritten for everyone. A transform registered on
  the TTS service still rewrites only what is spoken. A transform that leaves nothing but
  whitespace drops the aggregation. `TextTransform` in `pipecat.utils.text.transforms`
  names the callable type.
