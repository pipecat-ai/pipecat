- Added `AnnouncementConfig` for controlling what the bot volunteers when async tool results are announced. Style is set per cardinality, since an application can't predict whether one tool or three will finish together: one result is stated outright (`AnnouncementStyle.RESULT`), while several at once are offered rather than delivered (`NOTIFY`), because reading out a whole batch is a wall of speech nobody asked for. The instruction text for each case is configurable with `single_prompt` and `multiple_prompt`; an unknown placeholder is rejected when the config is constructed rather than mid-call. To announce nothing at all, have the tool deliver its final result with `FunctionCallResultProperties(run_llm=False)` — the result still lands in context to answer a later question, but never interrupts.
