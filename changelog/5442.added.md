- Added `LatencyBreakdown.segments`, a contiguous breakdown of the user-to-bot interval where each span begins as the previous one ends, so the durations sum to the measured latency. Unlike the per-service TTFB entries, which are sub-intervals, the segments also account for the pipeline hops between services, the tokens a turn-completion marker occupies before any speakable text, and the holds while an incomplete user turn waits for the user to continue. `LatencyBreakdown.segment_lines()` formats them for logging.
