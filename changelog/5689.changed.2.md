- ⚠️ **Breaking change:** `BackendOutput` no longer carries `is_final`. A backend's outputs are a stream with no final one: a `BackendLLMWorker` sends every turn its model writes as it is produced, whether an `LLMWithBackend` or an `OpenAILiveLLMService` client delegation is attached, and says when it has nothing left to do. `transform_output` is called as `transform_output(output)`, may return `None` to send nothing for an output, and what it returns is sent as is, empty text included. What the model writes in a turn with no tool calls asks to be spoken (`prefers_spoken=True`); what it writes beside tool calls, and a reasoning summary, do not; the text it gives the built-in `report_result` tool does. The transform is where to change that.
