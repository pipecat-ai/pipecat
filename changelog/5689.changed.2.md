- ⚠️ **Breaking change:** `BackendOutput` no longer carries `is_final`. A backend's outputs are a stream with no final one: a `BackendLLMWorker` sends every turn its model writes as it is produced, whether an `LLMWithBackend` or an `OpenAILiveLLMService` client delegation is attached, and says when it has nothing left to do. `transform_output` is called as `transform_output(output)`, may return `None` to send nothing for an output, and what it returns is sent as is, empty text included. A message the model begins with `>>` asks to be spoken (`prefers_spoken=True`) and arrives without the mark; anything else it writes, a reasoning summary included, does not. The transform sees each output after that, and is where code can change it.
