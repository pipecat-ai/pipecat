- ⚠️ **Breaking change:** `BackendLLMWorker` calls its `transform_output` callback as `transform_output(output, is_final=...)`, and `BackendOutput` no longer carries `is_final`: whether an output is the backend's final one is now told to the callback, not read off the output. A transform written with the old one-argument signature is rejected when the worker is constructed, with the expected signature in the error. A transform returns `None` to send nothing for an output (for the final output, settling the delegation with nothing for the frontend to speak); an output whose text it leaves empty is sent as is, where before it was dropped. A transform that raises now fails the delegation at once, where before the delegation waited out its timeout.
