- ⚠️ **Behavior change:** `max_context_tokens` in `LLMAutoContextSummarizationConfig` now bounds the summarizable context instead of the total context: only the messages a summary would actually compress count toward the trigger threshold. The preserved initial system message, the last `min_messages_after_summary` messages, and unresolved function call sequences no longer count, since summarization can never compress them. If you tuned `max_context_tokens` against your model's total context window, subtract your system prompt's estimated tokens and the typical size of the recent messages you keep to get the same trigger point.
