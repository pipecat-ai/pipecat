- `ElevenLabsTTSService` and `ElevenLabsDialogueTTSService` now close every server-side context still open before asking ElevenLabs to close the socket. ElevenLabs acts on `close_socket` only while no context is open, and a context-less keepalive left the default context open, so the disconnect on the `EndFrame` path waited out its full 2 s ceiling after the first idle keepalive. A closed context is also no longer named by later keepalives.
