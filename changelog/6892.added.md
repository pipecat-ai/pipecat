- Added `PlaybackMarkFrame`, which the output transport pushes on only once the user has heard the audio queued before it. Subclass it for a frame that must act after the bot speaks, such as a transfer. Transports whose peer reports playback override `BaseOutputTransport.write_playback_mark()`; the FastAPI and websocket server transports do so with `TwilioFrameSerializer`, which sends Twilio's `mark` event and waits for Twilio to echo it. Other transports push the mark once the audio before it has been written. A mark the peer never reports is pushed after 5 seconds.
