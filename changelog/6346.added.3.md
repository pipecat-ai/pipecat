- Added `UserTurnCompletionFrame`, which an LLM service using turn-completion markers pushes upstream once per inference. Its `kind` is `"complete"`, `"short"`, `"long"`, or `None` when the response has no marker, and its `context_frame_id` is the id of the `LLMContextFrame` that started the inference. A tool call before any marker counts as `"complete"`.
