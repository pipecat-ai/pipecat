- Added `ZoomAIHttpTTSService`, text-to-speech with the Zoom AI Services Text-to-Speech API. Install it with `pipecat-ai[zoom-ai]`. `pipecat init` offers it as "Zoom AI".
    - Each sentence is one HTTPS request, and its audio streams back in the response. The API returns 44.1 kHz audio, which is resampled to the pipeline's output rate.
    - `Settings.voice` picks one of ten voices (default `jenna`); `Settings.speed` and `Settings.volume` set the rate and volume.
