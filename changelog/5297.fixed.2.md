- Fixed the development runner's LiveKit routes minting the same participant identity (`"User"`/`"Pipecat Agent"`) for every session. When sessions share a room — e.g. a fixed `LIVEKIT_ROOM_NAME` — LiveKit evicts the earlier connection whenever a new one joins with the same identity, silently dropping the previous caller. Identities are now suffixed with the session id so concurrent sessions in the same room no longer collide.
