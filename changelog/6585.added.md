- Added LLM extensions: pluggable features or behaviors of an LLM service. `BaseLLMExtension` (`pipecat.services.base_llm_extension`) is the base class, and each extension lives with its feature. An extension can do any of these:
  - add to the service's system instruction, after the application's prompt;
  - watch every frame the service processes, before the service handles it;
  - filter every frame the service pushes: hold it back, drop it, or add frames;
  - push frames of its own;
  - add built-in tools, which `builtin_tools()` returns as `LLMExtensionTool`s given the tools registered with the service, and which the service advertises on every inference and withdraws as the registry changes.

  An application attaches its extensions with `LLMService(extensions=[...])`, a component that has the service in hand with `LLMService.add_extension()`, and a settings update with `LLMSettings(extensions=[...])`, which adds to the extensions held; its entries are callables that build an extension for each service the update reaches.
