- Added `ZoomDecisionsClassifier` in `pipecat.classifiers.zoom.decisions.classifier`, a classifier backed by the Zoom Decisions API (`zoom-decisions` or `zoom-decisions-pro`) that can also see images. Install it with `pipecat-ai[zoom-ai]`.
  - `evals.judges.zoom_classifier` judges evals with it, and `--zoom` runs the `features-classifiers` examples against it.
