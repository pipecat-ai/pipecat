- Added Daily SIP client provisioning to `DailyRESTHelper`:
  `create_sip_client()`, `list_sip_clients()`, `get_sip_client()`,
  `delete_sip_client()`, and `rotate_sip_client_password()` wrap Daily's
  `/sip-clients` REST API, which provisions plain SIP credentials on your
  Daily domain that any SIP user agent — a `SIPTransport` bot included — can
  register with to receive and place calls directly, with no Daily room in
  the path.
