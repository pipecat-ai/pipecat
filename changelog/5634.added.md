- Added `pipecat flows validate`, which checks a flow config before a bot runs and reports every problem at once. Structure is always checked; `--tools tools.py` (a file or module name) checks that every tool and action handler the config names exists and is a valid direct function; `--var NAME=VALUE` checks the config's `{{ variables }}`. It also warns about nodes the flow can never reach, nodes it can never leave, and branch tables whose cases and default all lead to one node. Exit code 1 on errors, or on warnings with `--strict`; `--json` prints the report for editors and agents; `-` reads from stdin. The same check is available as `pipecat.flows.validate_flow()`, which returns a `FlowReport`.

  ```
  $ pipecat flows validate flow.yaml --tools tools.py
  flow.yaml: 1 error, 1 warning (structure, tools)
  error   node 'start' references tool 'pick', which is not in the tools
  warning node 'orphan' cannot be reached from 'start'
  ```
