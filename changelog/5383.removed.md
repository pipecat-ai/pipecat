- Removed the sunset `saarika:v2.5` and `saaras:v2.5` models from `SarvamSTTService`, leaving `saaras:v3` and `saaras:v4` as the supported models. The `prompt` setting, the `set_prompt()` method, and the `speech_to_text_translate_streaming` endpoint path went with them, as all three were only reachable through `saaras:v2.5`. Applications using either model should move to `saaras:v4`.
