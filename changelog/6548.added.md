- Added HeyGen Voice text-to-speech services. Both default to the `heygen-voice-1-turbo` model and the public voice Nadine.
  - `HeyGenTTSService` streams text over HeyGen's `multi-stream-input` WebSocket. Per-character alignment drives word-level text frames, so an interruption commits only the words actually spoken. It takes HeyGen's `enable_ssml_parsing`, `enable_logging` and `end_user_id` options, and `apply_text_normalization` and `expressiveness_boost` as settings. `pipecat create` offers it.
  - `HeyGenHttpTTSService` streams raw PCM from the `/v3/models/audio/tts/stream` endpoint, one request per sentence. It also serves professional voice clones.

    ```python
    from pipecat.services.heygen.tts import HeyGenTTSService

    tts = HeyGenTTSService(
        api_key=os.environ["HEYGEN_API_KEY"],
        settings=HeyGenTTSService.Settings(voice="<voice_id>"),
    )
    ```
