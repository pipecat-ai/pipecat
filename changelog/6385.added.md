- Added `PipecatToneTagger` to expressive conversation (alpha), a processor that writes the expression tags for an LLM's plain replies with Pipecat Tone's tagger model. Placed between the LLM and the TTS service, it labels each sentence with a delivery, slow spans for details, stressed words and sounds, from the call so far, how the user sounded and the expression policy's presets, and writes them in the names the TTS service performs, trying an optional `vocabulary` of your own names first. The model downloads from Hugging Face the first time, at an optional `size` (`"17m"` or `"32m"`) and `revision`, or comes from an optional `model_dir` of your own. It loads while the pipeline is set up, once a process for every tagger to share, and runs on the CPU; if it can't load, the LLM writes the tags itself. Install it with `pipecat-ai[tone]`. See `examples/expressive-conversation/expressive-conversation-tone-tagger.py`.
