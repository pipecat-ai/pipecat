- Tool call options gain `async_tool`, which says whether the LLM carries on while the call runs and is handed the result later in a message of its own, separately from whether an interruption cancels the call. It is available on `tool_options`, `register_function`, `register_direct_function`, and the LLMWorker `@tool` decorator. Its default is `not cancel_on_interruption`, so `cancel_on_interruption=False` on its own still makes a tool async and existing tools are unchanged. An async tool that also cancels on interruption logs a warning at registration, since an interruption is broadcast whenever the user starts a turn.
