- Added a `strict` argument to `FunctionSchema`, which requests OpenAI's strict function-calling mode on the Responses API so tool arguments are guaranteed to match the schema. The Responses adapter also emits the `additionalProperties: false` that strict mode requires on every object in `parameters`, including nested ones, which OpenAI rejects the request without. It defaults to `None`, leaving the choice to the provider, and is read off the schema rather than carried in `to_default_dict()`, so providers with no strict mode are unaffected.
