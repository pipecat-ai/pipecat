- Fixed the user idle timeout firing while an `LLMWithBackend` backend works on a delegated task. `UserIdleController` treats such work, like an asynchronous function call, as something the conversation is waiting on, and times that wait instead: `LLMUserAggregatorParams.user_waiting_timeout` (and the same argument on `UserTurnProcessor`) emits `on_user_waiting` after that many seconds of quiet with work in flight, so the bot can reassure the user however the app likes.
