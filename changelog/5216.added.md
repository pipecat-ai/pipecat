- Added `BaseUIWorker`, a worker that can surface its jobs and job groups on the client UI without involving an LLM: pass `ui=UIJobGroupOptions(label=..., cancellable=...)` to its `job(...)`, `job_group(...)`, `request_job(...)`, or `request_job_group(...)` and the work's lifecycle streams to the client as the standard `ui-job-group` envelopes, with the client's reserved `__cancel_job_group` event honored for groups registered as cancellable. It is instantiable directly — register one on the runner as a dispatcher and call it from tools — and `UIWorker` now inherits from it, so a page-driving LLM worker keeps the same capability. `BaseWorker` itself is unchanged. The `async-tasks` example now fans out research through a `BaseUIWorker` dispatcher from the main pipeline's own LLM tool — one LLM instead of two — while `document-review` (which genuinely needs a page-reading LLM) keeps its `UIWorker`.
