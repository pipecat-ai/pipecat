- Fixed `SpeechmaticsSTTService` opening a session Speechmatics rejects (`audio_format.sample_rate does not match: 16000`) on any pipeline not running at 16 kHz, such as the 8 kHz telephony configuration `pipecat init` generates. Agent STT, which the service has targeted since 1.10.0, accepts 16 kHz only, so audio is now resampled to that rate before it is sent and the session declares that rate rather than the pipeline's. The conversion is from the rate the pipeline delivers, so a `sample_rate` override cannot declare a rate the audio does not have.
