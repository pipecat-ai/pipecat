- Added `MetaSTTService`, a streaming speech-to-text service using Meta's `muse-voice-transcribe-1.0` model over the Muse Voice realtime API. Install it with `pipecat-ai[meta]`, or pick Meta when scaffolding with `pipecat init`. `MetaSTTService.Settings` takes `language` or `language_bias` to bias recognition across the 25 supported languages, `keywords` for domain-specific terms, and `mode` to select the model's own endpointing, client-delimited turns, or diarization.
