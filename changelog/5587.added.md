- Added `MetaSTTService`, a streaming speech-to-text service using Meta's `muse-voice-transcribe-1.0` model over the Muse Voice realtime API. Install it with `pipecat-ai[meta]` and select it in `pipecat init`. `MetaSTTService.Settings` takes `language` or `language_bias` to bias recognition across the 25 supported languages, `keywords` to bias it toward domain-specific terms, and `mode` to choose between the model's own endpointing, client-delimited turns, and diarization.

    The model detects utterance boundaries itself, emitting cumulative partial transcripts and then a punctuated final transcript once a turn completes. The API offers no client-side finalize, so that final arrives when the model decides the turn ended rather than when the pipeline's VAD signals end of speech.

    The API accepts 24 kHz or 16 kHz audio. The service sends either rate untouched and resamples anything else to 16 kHz, so telephony transports work without extra configuration.
