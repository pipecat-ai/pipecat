- A voice LLM can now ask a `UIWorker` about the screen without ever seeing it. The worker answers these jobs with short data: `find` (which element matches a description), `check` (whether something is true on screen), `select` (which elements match a description), `act` (find an element and click it, scroll to it, highlight it, select its text or fill it) and `elements` (what is on screen). `screen_tools("ui")` gives the voice LLM one tool for each of them.

  ```python
  context = LLMContext(tools=[*screen_tools("ui")])
  ```
