- A voice LLM can now ask a `UIWorker` about the screen without ever seeing it, through one job, `screen`, with an `action`: `find` (which element matches a description), `check` (whether something is true on screen), `select` (which elements match a description), `list` (what is on screen, with each input's value) and `click`, `scroll_to`, `highlight`, `select_text` or `fill` (do that to the element a description names). Every answer is short data. `screen_tools("ui")` gives the voice LLM the tool that sends it.

  ```python
  context = LLMContext(tools=screen_tools("ui"))
  ```
