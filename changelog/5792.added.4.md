- `VoicemailDetector` accepts `judge=TypeSafeJudge()` in place of a classifier LLM. Each caller turn is then one TypeSafe `Choice` between a live person and a recording, judged on the transcript so far, with a `confidence_threshold` below which the detector waits for more speech. `examples/features/features-voicemail-detection.py` now detects voicemail this way.
