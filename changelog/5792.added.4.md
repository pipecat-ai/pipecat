- Added `TypeSafeChoiceLLMService`, an LLM service that answers each turn with one label from a fixed set, chosen by a TypeSafe `Choice`, with no text generated. It plugs in wherever a "respond with one of these words" classifier LLM does. `TypeSafeVoicemailClassifier` (`pipecat.extensions.voicemail.typesafe_classifier`) is the preset for `VoicemailDetector(llm=...)`: one judgment per caller turn on the transcript so far, and a `confidence_threshold` below which it answers nothing so the detector waits for more speech. `examples/features/features-voicemail-detection.py` now detects voicemail this way.
