- Added `PIPECAT_LOG_LLM_CONTEXT` and `configure_logging(llm_context=...)` in `pipecat.utils.log_config` to control the LLM context that LLM services log at DEBUG level. Set it to `off` to keep DEBUG logging without the context dump, which repeats the whole conversation on every inference; `full`, the default, logs every message.

  ```python
  from pipecat.utils.log_config import LLMContextLogMode, configure_logging

  configure_logging(llm_context=LLMContextLogMode.OFF)
  ```
