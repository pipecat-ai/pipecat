- Added `PIPECAT_LOG_LLM_CONTEXT` to control how much of the LLM context LLM services include in their DEBUG logs. With `off`, each response is still logged, but without the context, which otherwise repeats the whole conversation on every inference; `full`, the default, includes every message. An unknown value raises `InvalidEnvVarValueError` when an LLM service is created.

  ```bash
  PIPECAT_LOG_LLM_CONTEXT=off python bot.py
  ```
