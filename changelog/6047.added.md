- Added `PIPECAT_LOG_LLM_CONTEXT` and `configure_logging(llm_context=...)` in `pipecat.utils.log_config` to control how much of the LLM context LLM services include in their DEBUG logs. With `off`, each response is still logged, but without the context, which otherwise repeats the whole conversation on every inference; `full`, the default, includes every message.

  ```python
  from pipecat.utils.log_config import LLMContextLogMode, configure_logging

  configure_logging(llm_context=LLMContextLogMode.OFF)
  ```
