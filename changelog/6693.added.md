- A function call handler that is cancelled, by an interruption, a timeout or the LLM, can now report how far it got. It catches its `asyncio.CancelledError` and calls `params.result_callback(...)` before re-raising, and the report settles the call in the context in place of the notice that its outcome is unknown, so the LLM can tell the user, for example, that a refund request had already been sent. The report travels on the new `FunctionCallCancelFrame.result` field, and the OpenAI Realtime, OpenAI Live, Grok and Inworld services send it to their APIs.

  ```python
  async def issue_refund(params: FunctionCallParams):
      sent = False
      try:
          await payments.send_refund(params.arguments)
          sent = True
          receipt = await payments.wait_for_confirmation()
          await params.result_callback({"status": "refunded", "receipt": receipt})
      except asyncio.CancelledError:
          await params.result_callback({"status": "submitted" if sent else "not_sent"})
          raise
  ```
