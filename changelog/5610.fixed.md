- `ErrorCategory.QUOTA` (HTTP 402, credit or allowance exhausted) is now a permanent category: the failing service loses its usability, so `ServiceSwitcherStrategyFailover` can select a backup instead of retrying a creditless provider for the rest of the run. HTTP 429 stays `RATE_LIMIT` and transient. Permanence is judged at run scope; an application that knows its allowance window has reset can restore the service with `set_usable(True)`.
