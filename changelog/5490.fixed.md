- Fixed `OpenAIResponsesLLMService` reporting a bare `Response failed` or `Response incomplete` for every terminal error over WebSocket. It read the detail from `status_details`, a Realtime field that the Responses API never sends, so the server's own error message and the truncation reason were both dropped. It now reads `error.message` on `response.failed` and `incomplete_details.reason` on `response.incomplete`, producing the same error text `OpenAIResponsesHttpLLMService` already does.
