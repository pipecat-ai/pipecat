- Added `language_codes` setting to `AssemblyAISTTSettings`, exposing AssemblyAI's list-valued declared-language parameter which supersedes the singular `language_code`. A single code (e.g. `language_codes=["es"]`) pins transcription to that language, while several codes (e.g. `language_codes=["en", "es"]`) steer toward that subset while keeping code-switching among them. Steering is prompt-based, so it applies to U3 Pro models only; on those models a change applies to the live connection instead of reconnecting, and an empty list clears steering back to the model default.
