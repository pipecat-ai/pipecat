- Fixed `GoogleLLMService` returning `400 INVALID_ARGUMENT` ("Please ensure that function call turn comes immediately after a user turn or after a function response turn") when the model's first action in a context holding no user-authored message was a tool call, as happens on a Flows node using `ContextStrategy.RESET` with `respond_immediately=True`. Affects synchronous and asynchronous tools alike. Those requests now open with a `"."` user turn anchoring the call.
