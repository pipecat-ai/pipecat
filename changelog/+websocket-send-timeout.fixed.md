- Websocket-based services now bound each websocket send at 10 seconds. A peer that stopped reading left the send waiting on a full write buffer, which stalled the service's processor and every processor behind it until TCP gave up, with no error or reconnect. A send that outlasts the bound now drops the connection and raises `ConnectionError`, so the service's reconnect logic takes over. The bound is configurable per service via the new `ws_send_timeout` argument on `WebsocketService`; pass `None` to wait indefinitely.
