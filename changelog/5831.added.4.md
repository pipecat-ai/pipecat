- Under the eval transport, a `flow_config` key in the `--runner-body` file is
  now the session's flow, the same as one sent to `/start`. An eval manifest
  sets `spawn:` once for the whole suite, so `--flow` cannot differ between
  entries; `runner_body:` is an entry's own, which lets one suite run several
  flows against the same bot. `--flow` remains the default for an entry whose
  body names no flow.
