- Added `finalize_on_vad_stop` to `GladiaSTTService`: when enabled, the service sends `{"type": "finalize"}` to Gladia when the VAD detects the end of speech, so the final transcript arrives right away instead of after Gladia's endpointing (the final is marked `from_finalize` and pushed as finalized). Off by default: it needs a Gladia API that supports `finalize`.
