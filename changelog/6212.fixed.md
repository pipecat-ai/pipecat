- `AWSBedrockLLMService`, `AWSPollyTTSService`, `AWSAgentCoreProcessor` and `AWSTranscribeSTTService` keep working past the expiry of temporary credentials from the default AWS chain (IRSA, EKS Pod Identity, ECS task roles, EC2 instance profiles, SSO). They used to copy those credentials once at construction and fail with expired-token errors once the copy expired; the AWS session now renews them, and Transcribe signs each connection with current keys.
