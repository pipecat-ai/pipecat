- Fixed `bot-output` missing the last sentence of a speech-to-speech reply when the pipeline uses an `LLMTextProcessor` (e.g. with `OpenAIRealtimeLLMService` or `GeminiLiveLLMService`). The bot spoke that sentence, but clients never received it. `LLMTextProcessor` now flushes the text it holds when it receives a `TTSStoppedFrame`, so the sentence goes out while the bot is still speaking.
