- Added `acquires` and `releases` (`pipecat.utils.shared`) for a resource shared by several processors, such as the client an input and an output transport share. The first owner to acquire runs the decorated method while the rest wait for it, and only the last owner to release runs the undo.

    ```python
    class MyTransportClient:
        @acquires("client")
        async def setup(self, setup: FrameProcessorSetup): ...

        @releases("client")
        async def cleanup(self): ...
    ```
