- Added an `on_word_timestamps` event to `TTSService`. It reports the words a provider timed for a context as `(word, start, end)` tuples, in seconds from the start of the context's audio, so an application can align each word with the audio it was spoken in. `add_word_timestamps()` takes an optional `word_ends` list for providers that report where each word ends, and `CartesiaTTSService` now passes Cartesia's word ends.
