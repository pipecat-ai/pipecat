- Fixed the Twilio, Telnyx, Plivo, Exotel, Vonage and Protobuf frame serializers
  ending the call when they received a message of an unexpected shape: JSON that
  is not an object, a `null` `media` or `dtmf`, an undecodable base64 payload, or
  bytes that are not a valid protobuf message. Such messages are now logged and
  ignored. `FrameSerializer.should_ignore_frame()` also no longer raises for an
  `OutputTransportMessageFrame` whose message is not a dict.
