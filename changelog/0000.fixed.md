- `AWSBedrockLLMService` no longer sends Amazon Nova's `<thinking>...</thinking>` chain of thought to TTS. Nova (v1) models write it into the answer text before calling a tool, so voice bots read it aloud. A leading `<thinking>` block is now emitted as `LLMThoughtStartFrame` / `LLMThoughtTextFrame` / `LLMThoughtEndFrame`, like `NvidiaLLMService` does for `<think>`.
