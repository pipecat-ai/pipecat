- Added user turn filters. The user turn stop strategies propose that the user is done, and a filter set with `LLMUserAggregatorParams(user_turn_filter=...)` decides whether that turn end stands: the turn ends once the filter accepts, and a rejection keeps it open and drops the answer generated for it. The answer is held until the filter decides, so it is never spoken for a rejected turn. A filter works on top of whatever user turn strategies a service recommends, including eager end of turn: the filter judges the speculative answer while it is generated, and the turn ends once the turn commits and the filter accepts. A filter is ignored, with a warning, with a realtime LLM service. Without a filter, user turns end as before. Custom filters subclass `BaseUserTurnFilter` from `pipecat.turns.user_turn_filter`.
