- Async function calls (`cancel_on_interruption=False`) now keep settling as ordinary tool results when only assistant output lands in the context while they run, such as filler a tool handler speaks with `TTSSpeakFrame`. Previously that filler turned the result into a deferred-result message, while the same filler spoken from `on_function_calls_started` did not. The result is still deferred when a user or developer message arrives first, or when the call sent an intermediate update.
