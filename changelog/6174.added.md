- `LLMWithBackend(predictive_delegation=PredictiveDelegation(classifier))` is an optimization that can speed up responses that need backend involvement. It uses a fast yes/no classifier (such as `JevClassifier`) to determine, after each user request, whether it needs to wait for a frontend inference or can go ahead and trigger an early backend delegation. The cost is money, not time: the classifier runs in parallel with the frontend, but on every turn, and an early delegation abandons a frontend request already under way. Only text frontends are supported, and only request strategies that have `BackendRequestStrategy.delegate_needs_arguments` set to `False` (like `TranscriptBackendRequestStrategy`).
