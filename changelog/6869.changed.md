- `SarvamRealtimeSTTService` now defaults to `saaras:v4`, Sarvam's current default for its realtime endpoint. The previous default, `saaras:v3-realtime`, is in beta, and Sarvam refuses it for API keys not enrolled in the beta, so a service built without a model couldn't connect for most keys. Select `saaras:v3-realtime` through `Settings(model=...)` to keep using it.
