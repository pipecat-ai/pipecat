- Added `TypeSafeChoiceRouter` and its Flows binding `FlowsTypeSafeRouter`. Placed after the user context aggregator, they judge a user turn with a TypeSafe `Choice` and hand a confident match to code, which can answer with canned speech or move a flow to another node, so the LLM does not run for that turn. Unsettled turns go to `on_fallthrough` or continue to the LLM. See `examples/features/features-typesafe-canned-routing.py` for a bot with no LLM at all.
