- Added a `vad_force_turn_endpoint` argument to `DeepgramFluxSTTService` and `DeepgramFluxSageMakerSTTService`. It defaults to `False`, where Flux decides when user turns end. `True` hands that decision to the pipeline's own user turn strategies — a smart-turn analyzer, an LLM completion gate, or anything else — while local VAD asks Flux to finalize each segment via `ForceEndTurn`. Setting `eot_threshold=1.0` alongside it stops Flux finalizing on its own confidence as well. The service also exposes `force_end_turn()` for finalizing on other signals, such as a push-to-talk release.
