- Fixed a function call result never running the LLM when a user mute strategy, such as `FunctionCallUserMuteStrategy`, muted the user during their turn. `LLMAssistantAggregator` held the result for that turn to end, so the bot stayed silent until the user spoke again. A user muted during their turn is no longer waited for, for the rest of that turn: a held result, cancellation, or `LLMMessagesAppendFrame` with `run_llm=True` runs as soon as it can, even while the user is still speaking. An empty user turn already answered that way doesn't also run empty user turn recovery.
