- Added the remaining documented Grok Voice Agent session parameters to `GrokRealtimeLLMService`'s `SessionProperties`: `turn_detection` now carries `threshold`, `prefix_padding_ms`, `silence_duration_ms` and `idle_timeout_ms`; `audio.input` carries a new `InputAudioTranscription` (`language_hint`, `keyterms`); `audio.output` carries `speed`; and the session carries `reasoning` (`effort`). Every field defaults to `None` and client events serialize with `exclude_none=True`, so the `session.update` payload is unchanged unless a field is set. Configuring transcription means constructing an `AudioInput`, which used to leave the session without a sample rate — `_ensure_audio_config` now backfills a missing `format` field-by-field and leaves user-supplied formats alone.
