- Added `enable_agent_text_input` to `SonioxSTTService.Settings`, on by default. Each reply is sent to Soniox once the bot has said it, so the recognizer knows the bot's side of the conversation and words the bot used are recognized when the user repeats them. It takes effect only on models that support agent text input (`stt-rt-v6` and later); it stays off for older models.
