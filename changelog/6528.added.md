- Added `enable_agent_text_input` and `enable_echo_cancellation` to `SonioxSTTService.Settings`, which feed what the agent is saying back into the STT session. The first sends each reply once, after the agent said it, and works with any TTS service. The second times each word to the TTS output, `agent_text_lead_ms` (700ms) before the user hears it, which is what gives you echo cancellation; it needs a TTS service that reports word timestamps, such as `SonioxTTSService`. Both need a model with agent text input, such as `stt-rt-v6`.
