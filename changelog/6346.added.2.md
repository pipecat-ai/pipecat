- Added `start_mode=StrategyMode.ALL` to `UserTurnStrategiesParams`, which starts a user turn only once every start strategy agrees. `WakePhraseUserTurnStartStrategy` votes when it hears the wake phrase and, while awake, whenever the user starts speaking, so `start=[VADUserTurnStartStrategy(), WakePhraseUserTurnStartStrategy(...)]` in an `ALL` list starts a turn on speech only after the wake phrase, in either order.
