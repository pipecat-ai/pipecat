- Added `JambonzFrameSerializer`, for connecting a Pipecat pipeline to [jambonz](https://jambonz.org) through its `listen` verb. jambonz sends raw 16-bit PCM rather than base64 in a JSON envelope, and announces the call's sample rate, channel layout and identifiers in a preamble before any audio, so the rate is read from the connection rather than configured — a narrowband call needs no change. Later text frames are events: a DTMF digit becomes an `InputDTMFFrame` when the verb sets `passDtmf`, and `mark` and `playDone` replies are ignored. `InterruptionFrame` sends `killAudio`, and `disconnect_on_end` (on by default) ends the `listen` verb when the pipeline stops, which needs no API credentials.

  The verb has to set three things explicitly. `streaming` defaults to `false`, and while it is, audio sent back is ignored and the caller simply hears nothing. `sampleRate` defaults to `8000`. And `bidirectionalAudio.sampleRate` has no default — omitted, your audio is read at the call's negotiated codec rate, which depends on the carrier. jambonz resamples whatever arrives at that rate, but this serializer sends at the `sampleRate` it read from the preamble, so set the two to the same value:

  ```json
  {
    "verb": "listen",
    "url": "wss://your-bot.example.com/ws",
    "sampleRate": 16000,
    "mixType": "mono",
    "bidirectionalAudio": { "enabled": true, "streaming": true, "sampleRate": 16000 }
  }
  ```

  ```python
  from pipecat.serializers.jambonz import JambonzFrameSerializer

  transport = FastAPIWebsocketTransport(
      websocket=websocket,
      params=FastAPIWebsocketParams(serializer=JambonzFrameSerializer()),
  )
  ```
