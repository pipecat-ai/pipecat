- Added `JambonzFrameSerializer`, for connecting a Pipecat pipeline to [jambonz](https://jambonz.org) through its `listen` verb. jambonz sends raw 16-bit PCM rather than base64 in a JSON envelope, and announces the call's sample rate and identifiers in a preamble before any audio, so the rate is read from the connection rather than configured — a narrowband call needs no change. `InterruptionFrame` sends `killAudio` and then withholds audio briefly, because message ordering on the socket is not guaranteed and a frame written in the same moment can arrive after the flush.

  ```python
  from pipecat.serializers.jambonz import JambonzFrameSerializer

  transport = FastAPIWebsocketTransport(
      websocket=websocket,
      params=FastAPIWebsocketParams(serializer=JambonzFrameSerializer()),
  )
  ```
